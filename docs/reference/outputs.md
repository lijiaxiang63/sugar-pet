# Output files

A page-by-page summary of all files written by SUGAR-PET. `sub-01` denotes
the input filename without `_pet.nii.gz`; `<method>` denotes the method's
short name without hyphens (`hn`, `cerebellum`, `whitematter`, …).

The CLI writes the exact same files and filenames, so folders generated by
either tool are completely interchangeable.

## Spatial Normalisation

| File | Description |
| --- | --- |
| `sub-01_space-MNI_pet.nii.gz` | Warped image in MNI space, 2 mm isotropic voxels |

## Reference

A single folder (the *reference*) containing:

| File | Contents |
| --- | --- |
| `reference.json` | Control count, smoothing kernel, mask, and each control's factor |
| `template.nii.gz` | Mean of the controls after proportional scaling |
| `ps_std.nii.gz` | Standard deviation of the controls after PS |
| `hn_mean.nii.gz`, `hn_std.nii.gz` | Mean and standard deviation of the controls after HN |
| `mask.nii.gz` | Voxels used to estimate the factors |
| `stats-<method>_mean.nii.gz`, `…_std.nii.gz` | Created only for methods ticked under *Z-score maps with other methods* |
| `model-<method>_beta.nii.gz`, `…_sd.nii.gz` | Created only when a covariate table is provided: regression parameters for uptake vs. covariates |

## Intensity Normalisation

| File | Description |
| --- | --- |
| `sub-01_desc-<method>_pet.nii.gz` | Image divided by its factor (one per image and method) |
| `sub-01_desc-<method>_pet_mask.nii.gz` | When *Save masks* is enabled: voxels used to estimate the factor |
| `factors.tsv` | Summary table with one row per image and method |

Columns in `factors.tsv`:

| Column | Description |
| --- | --- |
| `image` | Path to the input image |
| `method` | Short name of the method |
| `factor` | Estimated normalisation factor |
| `n_voxels` | Number of voxels used in estimation |
| `excluded_fraction` | iPS and iHN only: fraction of voxels excluded |
| `mask` | Region used |

## Z-score Maps

| File | Description |
| --- | --- |
| `sub-01_desc-<method>_zmap.nii.gz` | Z-score map (no covariate table) |
| `sub-01_desc-<method>_wmap.nii.gz` | W-score map (with a covariate table) |

## Classify Parkinsonism

| File | Description |
| --- | --- |
| `sub-01_report.html` | Standalone HTML report, printable to PDF |
| `sub-01_desc-hn_wmap.nii.gz` | Underlying deviation map (`_zmap` when no covariate table is given) |
| `sub-01_classification.json` | Structured numerical outputs behind the report |
| `classification.tsv` | Summary table with one row per image: conclusion and pattern scores |

## Compare Groups

`<name>` is the *Name of the result files* (`group1_vs_group2` by default).

| File | Description |
| --- | --- |
| `<name>_T.nii.gz` | Unthresholded T-map (group 1 minus group 2) |
| `ClusterThresholded_<name>_T.nii.gz` | T-map masked to clusters surviving multiple-comparison correction |
| `ClusterReport_<name>_T.csv` | One row per cluster: size, peak, AAL and Harvard-Oxford regions |
| `<name>_factors.tsv` | Normalisation factor for every image |
| `<name>_mask.nii.gz` | Voxels included in the test |
| `<name>_beta.nii.gz`, `<name>_cohen_f2.nii.gz` | Model coefficients and effect size |

## Reference Cluster

| File | Description |
| --- | --- |
| Your chosen file, e.g. `reference_cluster.nii.gz` | Binary mask of the voxels forming the reference region |

## Masks & Atlas

**Export All as NIfTI…** writes one `.nii.gz` file per built-in mask—named
after its short name—into the selected folder.
