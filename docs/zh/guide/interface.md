# 认识界面

软件的每个页面都采用相似的布局和控件。提前熟悉一下这些通用区域，后面看教程会轻松很多。

<Shot name="normalize" alt="窗口的各个部分" :marks="[[1, 216, 112], [2, 222, 830], [3, 110, 874], [4, 163], [5, 492], [6, 257, 862], [7, 'run']]" />

1. **功能导航栏**：左侧边栏按常规分析顺序排列了各个功能页面，并分为几组：准备研究和参考库、单个患者的分析、组水平的分析。点击即可切换。上一次运行成功的页面后面会打勾，正在运行的页面显示转圈，两者都没有的页面显示已添加的图像数。
2. **当前参考库**：显示当前选中的健康对照参考库文件夹，点击可以更换。参考库是全局共享的——在任意页面建好或打开一个参考库后，其他页面都会自动使用它。使用研究文件夹之后，它上方还会出现一张显示该文件夹的卡片，点击可打开“研究文件夹”页面。
3. **设置**：打开[设置窗口](#settings)，界面语言、软件更新以及各项分析的选项都在那里。旁边的数字是当前版本号；有新版本可用时，这里会变成**有新版本**的标记。
4. **图像列表**：用于添加待处理的图像（详见[下文](#file-lists)）。
5. **运行必填项**：按卡片分组的勾选方块、下拉菜单和路径选择器，每组标题下方通常附有简短的提示说明。页面上只保留一次运行必不可少的内容：图像、方法、参考库和输出位置。
6. **状态栏**：运行前会提示还缺少哪些必填项（例如“请选择输出文件夹。”），运行中显示进度，结束后提示成功或报错信息。
7. **执行按钮**：点击后开始处理，运行期间按钮会变为**取消**。同一时间只能运行一个任务。

## 图像列表 {#file-lists}

应用只接受 NIfTI 格式的图像（`.nii` 或 `.nii.gz`）。你可以通过三种方式添加文件：

* 直接把文件或整个文件夹**拖放**到列表区域；
* 点击**添加文件…**逐个挑选；
* 点击**添加文件夹…**批量导入整个目录下的图像。

列表标题旁会实时显示当前已添加的图像数量。点击每行末尾的 **×** 可以移除单个文件，点击**清空**则清空整个列表。文件名右侧标注了它所在的文件夹路径，方便在存在同名文件时加以区分。

## 选择文件夹与文件

需要指定路径的设置项在未选择时会显示**选择…**；选好后按钮变为**更改…**，旁边显示当前路径名称，点击名称旁的 **×** 可以清除已选路径。

## 选项 {#options}

阈值、平滑、掩膜等大多数情况下无需改动的参数不再放在页面上，而是集中在[设置窗口](#settings)里，默认值均遵循对应文献的做法。为了让你随时知道当前用的是什么参数，每个页面的卡片下方都有一行文字，概括正在生效的选项。

<Shot name="normalize-output" alt="页面卡片下方的选项摘要" :marks="[[1, 391], [2, 1016, 391]]" />

1. **当前生效的选项**：用一行文字概括，例如图中的*区域均值 · 目标值 1 · 平滑自动*。如果有选项被改得与默认值不同，行尾会出现**已修改 1 项**这样的标记，把鼠标移上去可以看到具体是哪几项。
2. **选项…**：打开设置窗口，并直接跳到本页面对应的那一栏。

“Z 值图”页面只有在勾选了 iPS 或 iHN 时才显示这一行（该页面只有这两种方法有选项）；“研究文件夹”和“掩膜与图谱”页面没有选项。

## 设置窗口 {#settings}

点击侧边栏底部的**设置**，或按 <kbd>⌘</kbd> <kbd>,</kbd>（macOS）/ <kbd>Ctrl</kbd> <kbd>,</kbd>（Windows 和 Linux），也可以在 macOS 菜单栏中选择 **SUGAR-PET › 设置…**。设置是一个独立的窗口，可以和主窗口并排开着。改动立即生效并自动保存，没有“确定”按钮。

<Shot name="settings-general" alt="设置窗口的“通用”栏" :marks="[[1, 197, 134], [2, 170, 202], [3, 152], [4, 266], [5, 327]]" />

1. **分栏**：最上面是*通用*，下面每项分析各占一栏，放着对应页面上没有列出的选项：**空间标准化**（SPM、MATLAB 和模板）、**强度归一化**（其中 iPS 与 iHN 的选项同时用于“Z 值图”页面）、**参考库**、**帕金森综合征分类**、**组间比较**和**参考簇**。各栏的具体内容在教程的相应步骤中介绍。
2. **圆点**：表示这一栏里有选项被改得与默认值不同。这样的栏底部会列出改动了哪些选项，点击**恢复默认设置**可以把这一栏还原。
3. **界面语言**：English 或中文，切换后整个应用立即生效。
4. **版本与更新**：当前运行的版本、上次检查更新的时间，以及立即检查的**检查更新…**按钮。
5. **自动更新**：是否自动检查更新，以及是否自动下载并安装新版本。

### 软件更新 {#updates}

从 0.7.0 版开始，应用可以通过 [GitHub 发布页](https://github.com/lijiaxiang63/sugar-pet/releases)自行更新：启动后不久检查一次，此后每天检查一次。发现新版本时，会弹出窗口说明更新内容并询问是否安装；在你安装之前，侧边栏的**设置**旁会一直显示**有新版本**。打开*自动下载并安装*后，新版本会在后台下载，下次打开应用时生效。

通过 `.deb` 或 `.rpm` 软件包安装的应用由系统的包管理器负责更新，这时“通用”栏里给出的是发布页面的链接。0.6.0 及更早的版本没有自动更新功能，需要手动[安装](./install)一次新版本。

## 查看结果

任务跑完后，页面会自动滚动到底部的结果区。多数页面的结果以一幅图开头：画在横断面脑切片上的结果（叠加了模板轮廓的配准图像、Z 值图、T 图、参考簇），归一化因子的折线图，或各模式匹配度的柱状条。图片下方标注的 **R**、**L** 指患者的右侧和左侧。一次处理多幅图像时，可以用图片上方的箭头或点击表格中的某一行，来切换显示哪一幅。

图片下方是结果表格，以及**在访达中显示**（Windows 和 Linux 下为文件管理器）等快捷按钮，方便直接打开输出目录。如果个别图像在运行中出错，其余图像仍会正常完成，失败的原因会单独列在表格下方。

## 状态记忆

软件会自动记住你的界面语言、上次停留的页面、当前使用的参考库、输出目录、MATLAB 和 SPM 的路径，以及设置窗口里的全部选项，下次打开时无需重新配置。待处理的图像列表则不会保留，每次启动都是空的。
