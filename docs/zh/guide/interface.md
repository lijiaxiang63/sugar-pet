# 认识界面

软件的每个页面都采用相似的布局和控件。提前熟悉一下这些通用区域，后面看教程会轻松很多。

<Shot name="normalize" alt="窗口的各个部分" :marks="[[1, 216, 116], [2, 216, 185], [3, 216, 874], [4, 109], [5, 859, 299], [6, 506, 861], [7, 783, 861], [8, 930, 861]]" />

1. **项目**：当前打开的[项目](../tutorial/project)名称，以及其中的患者和对照人数。点击进入“数据”页面。
2. **功能导航栏**：按分析顺序排列的页面，分为几组：项目（数据，原始空间的图像还有空间标准化）、个案分析、组水平分析、项目之外的快速分类，以及掩膜与图谱。上一次运行成功、且仍建立在前面步骤之上的页面会打勾，正在运行的页面显示转圈，数字表示该页面还有多少幅图像待运行。
3. **设置**：打开[设置窗口](#settings)，界面语言、软件更新以及各项分析的选项都在那里。旁边的数字是当前版本号；有新版本可用时，这里会变成**有新版本**的标记。
4. **步骤条**：**个案分析**的三个页面（强度归一化、Z 值图、帕金森综合征分类）是连续的三步，原始空间的图像前面还有空间标准化。打勾表示该步已完成，点击可以切换。
5. **页面读取的内容**：图像只在“数据”页面添加；其他页面只读显示它们，并提供一个按钮跳到修改的地方，这里是**到“数据”页面修改**。同样，后一步只读显示前一步的方法，不再询问。
6. **状态栏**：运行前提示还缺什么（例如项目至少需要 3 例对照），运行中显示进度，结束后提示成功或报错。
7. **执行按钮**：点击后开始处理，运行期间变为**取消**。同一时间只能运行一个任务。
8. **下一步**：一步完成后，执行按钮旁会出现进入下一个页面的按钮。

页面所依据的内容（图像、选项、前面的步骤）在它上次运行之后有变化时，结果会保留，但页面会说明这一点，侧栏中的勾会消失，状态栏会指出需要重新运行哪个页面。

## 图像列表 {#file-lists}

图像在[“数据”页面](../tutorial/project#the-data-page)添加，这是唯一需要填写图像列表的页面。只接受 NIfTI 格式（`.nii` 或 `.nii.gz`），有三种添加方式：

* 直接把文件或整个文件夹**拖放**到列表上；
* 点击**添加文件…**逐个挑选；
* 点击**添加文件夹…**导入整个目录下的图像。

项目自己的 `patients/` 或 `controls/` 文件夹里有图像时，还会多出一个按钮（例如**加载项目的 patients/**），一键添加它们。

列表标题旁显示图像数量。点击每行末尾的 **×** 移除单幅图像，点击**清空**移除整个列表；都不会删除文件。所有图像来自同一个文件夹时，文件夹只在标题中显示一次；否则每个文件名旁标注它所在的文件夹，便于区分同名文件。

图像超过 8 幅时，列表上方会出现**筛选**框。筛选只影响显示哪些行：运行、计数和**清空**仍然针对整个列表。

## 选择文件夹与文件

需要指定路径的设置项在未选择时会显示**选择…**；选好后按钮变为**更改…**，旁边显示当前路径名称，点击名称旁的 **×** 可以清除已选路径。

## 选项 {#options}

阈值、平滑、掩膜等大多数情况下无需改动的参数不再放在页面上，而是集中在[设置窗口](#settings)里，默认值均遵循对应文献的做法。为了让你随时知道当前用的是什么参数，每个页面的卡片下方都有一行文字，概括正在生效的选项。

<Shot name="normalize-output" alt="页面上的一行选项" :marks="[[1, 414], [2, 904, 414], [3, 972, 414]]" />

1. **当前生效的选项**：一行概括，图中是对照统计的选项：掩膜、平滑，以及额外保存统计的方法。
2. **标记**：有选项与默认值不同时，行尾会出现**已修改 1 项**这样的标记，把鼠标移上去可以看到是哪几项。
3. **选项…**：打开设置窗口，直接跳到存放这些选项的那一栏。

“数据”和“掩膜与图谱”页面没有选项。

## 设置窗口 {#settings}

点击侧边栏底部的**设置**，或按 <kbd>⌘</kbd> <kbd>,</kbd>（macOS）/ <kbd>Ctrl</kbd> <kbd>,</kbd>（Windows 和 Linux），也可以在 macOS 菜单栏中选择 **SUGAR-PET › 设置…**。设置是一个独立的窗口，可以和主窗口并排开着。改动立即生效并自动保存，没有“确定”按钮。

<Shot name="settings-general" alt="设置窗口的“通用”栏" :marks="[[1, 196, 68], [2, 143], [3, 256], [4, 318]]" />

1. **分栏**：最上面是*通用*，下面每项分析各占一栏，放着对应页面上没有列出的选项：**空间标准化**（SPM、MATLAB 和模板）、**强度归一化**（包括 iPS 与 iHN 的选项）、**对照统计**（如何汇总对照）、**帕金森综合征分类**、**组间比较**和**参考簇**。各栏内容在教程的相应章节中介绍。有选项与默认值不同的栏会带一个圆点；这样的栏底部会列出改动了哪些选项，**恢复默认设置**可以把这一栏还原。
2. **界面语言**：English 或中文，切换后整个应用立即生效。
3. **版本与更新**：当前运行的版本、上次检查更新的时间，以及立即检查的**检查更新…**按钮。
4. **自动更新**：是否自动检查更新，以及是否自动下载并安装新版本。

### 软件更新 {#updates}

从 0.7.0 版开始，应用可以通过 [GitHub 发布页](https://github.com/lijiaxiang63/sugar-pet/releases)自行更新：启动后不久检查一次，此后每天检查一次。发现新版本时，会弹出窗口说明更新内容并询问是否安装；在你安装之前，侧边栏的**设置**旁会一直显示**有新版本**。打开*自动下载并安装*后，新版本会在后台下载，下次打开应用时生效。

通过 `.deb` 或 `.rpm` 软件包安装的应用由系统的包管理器负责更新，这时“通用”栏里给出的是发布页面的链接。0.6.0 及更早的版本没有自动更新功能，需要手动[安装](./install)一次新版本。

## 查看结果

任务跑完后，页面会自动滚动到底部的结果区。多数页面的结果以一幅图开头：画在横断面脑切片上的结果（叠加了模板轮廓的配准图像、Z 值图、T 图、参考簇），归一化因子的折线图，或各模式匹配度的柱状条。图片下方标注的 **R**、**L** 指患者的右侧和左侧。一次处理多幅图像时，可以用图片上方的箭头或点击表格中的某一行，来切换显示哪一幅。

图片下方是结果表格，以及**在访达中显示**（Windows 和 Linux 下为文件管理器）等快捷按钮，方便直接打开输出目录。如果个别图像在运行中出错，其余图像仍会正常完成，失败的原因会单独列在表格下方。

## 状态记忆

软件记住界面语言、最近打开的项目，以及 MATLAB 和 SPM 的路径。其余一切都属于项目，保存在它的文件 `sugar-pet-project.json` 中：图像、你在每个页面上的选择、设置窗口中的选项，以及每一步的结果。再次打开项目，一切都停在你离开时的样子。
