# 认识界面

软件的每个页面都采用相似的布局和控件。提前熟悉一下这些通用区域，后面看教程会轻松很多。

<Shot name="normalize" alt="窗口的各个部分" :marks="[[1, 208, 113], [2, 208, 664], [3, 208, 711], [4, 120], [5, 432], [6, 262, 688], [7, 'run']]" />

1. **功能导航栏**：左侧边栏按常规分析顺序排列了各个功能页面，点击即可切换。
2. **当前参考库**：显示当前选中的健康对照参考库文件夹，点击可以更换。参考库是全局共享的——在任意页面建好或打开一个参考库后，其他页面都会自动使用它。
3. **语言切换**：支持在中文和英文之间即时切换。
4. **图像列表**：用于添加待处理的图像（详见[下文](#file-lists)）。
5. **参数设置区**：按卡片分组的复选框、下拉菜单和路径选择器，卡片下方通常附有简短的提示说明。
6. **状态栏**：运行前会提示还缺少哪些必填项（例如“请选择输出文件夹。”），运行中显示进度，结束后提示成功或报错信息。
7. **执行按钮**：点击后开始处理，运行期间按钮会变为**取消**。同一时间只能运行一个任务。

## 图像列表 {#file-lists}

应用只接受 NIfTI 格式的图像（`.nii` 或 `.nii.gz`）。你可以通过三种方式添加文件：

* 直接把文件或整个文件夹**拖放**到列表区域；
* 点击**添加文件…**逐个挑选；
* 点击**添加文件夹…**批量导入整个目录下的图像。

列表标题旁会实时显示当前已添加的图像数量。点击每行末尾的 **×** 可以移除单个文件，点击**清空**则清空整个列表。文件名右侧标注了它所在的文件夹路径，方便在存在同名文件时加以区分。

## 选择文件夹与文件

需要指定路径的设置项在未选择时会显示**选择…**；选好后按钮变为**更改…**，旁边显示当前路径名称，点击名称旁的 **×** 可以清除已选路径。

## 高级选项

不常调整的参数都折叠在**选项**栏里，点击即可展开。这些参数的默认值均遵循对应文献的推荐设置，初次使用时保持默认即可。

## 查看结果

任务跑完后，页面会自动滚动到底部的结果区。除了展示结果表格外，还提供了**在访达中显示**（Windows 和 Linux 下为文件管理器）等快捷按钮，方便直接打开输出目录。如果个别图像在运行中出错，其余图像仍会正常完成，失败的原因会单独列在表格下方。

## 状态记忆

软件会自动记住你的界面语言、上次停留的页面、当前使用的参考库、输出目录，以及 MATLAB 和 SPM 的路径，下次打开时无需重新配置。待处理的图像列表则不会保留，每次启动都是空的。
