# SUGAR-PET 简介

SUGAR-PET 是一款专注于脑 FDG-PET **强度归一化**的桌面应用，同时也涵盖了归一化后的常见分析流程，包括个体偏离图（Z 值图 / W 值图）、帕金森综合征辅助分类以及组间统计比较。

## 为什么要做强度归一化？

FDG-PET 图像的体素值会受到注射剂量、血糖水平、体重等多种因素影响，因此不同扫描之间的原始数值无法直接对比。强度归一化的做法，就是把整幅图像除以一个**归一化因子**：

```
归一化后的图像 = 原图像 / 因子
```

软件里提供的各种方法，本质上只是估计这个因子的方式不同——有的取不受疾病影响的参考区均值，有的取全脑灰质均值，还有的通过对比图像与健康对照的比值直方图来找众数。具体怎么选，可以参考[方法怎么选](../reference/methods)。

## 注意区分两个“normalisation”

英文文献里常把空间配准和强度缩放都叫 normalisation，但它们其实是两个完全不同的步骤，在应用里也分属不同页面：

| | 空间标准化 | 强度归一化 |
| --- | --- | --- |
| 作用 | 把图像从扫描仪原始空间配准到 MNI 标准空间，让不同受试者的同一个体素对应同一个解剖位置 | 把图像除以各自的归一化因子，让不同图像之间的数值具有可比性 |
| 对应页面 | **空间标准化** | **强度归一化**及后续所有页面 |
| 依赖环境 | 需要 MATLAB 和 SPM12/SPM25 | 无需额外软件 |
| 何时使用 | 仅限原始空间的图像，在第 1 步之前 | 每次分析都需要：第 1 步 |

::: tip 你可能根本用不上 MATLAB
如果你的图像已经在 MNI 空间（无论之前是用 SPM、ANTs 还是其他工具处理的），在“数据”页面选择 MNI 空间，“空间标准化”页面就不会出现。应用其余的所有功能都不依赖 MATLAB、SPM 或 Python。
:::

## 功能页面一览

软件每次处理一个**项目**：一个文件夹，存放一项研究的患者和健康对照，以及各项分析写出的所有结果。侧栏按分析顺序列出它的页面：

| 页面 | 主要用途 |
| --- | --- |
| [数据](../tutorial/project) | 项目的图像：患者、至少 3 例健康对照，以及他们的年龄和性别 |
| [空间标准化](../tutorial/spatial) | 调用 SPM 把原始空间的图像配准到 MNI 空间（仅限原始空间的图像） |
| [强度归一化](../tutorial/normalize) | 第 1 步：把对照汇总成*对照统计*，再把每幅图像除以各自的因子 |
| [Z 值图](../tutorial/zmap) | 第 2 步：患者每个体素偏离对照的程度 |
| [帕金森综合征分类](../tutorial/classify) | 第 3 步：把每例患者的图与典型代谢模式比对，并生成报告 |
| [组间比较](../tutorial/compare) | 患者对对照的逐体素双样本 t 检验，带多重比较校正 |
| [参考簇](../tutorial/reference-cluster) | 由患者数据得出未受累的参考区 |
| [快速分类](../tutorial/quick) | 用项目的对照为项目之外的一例患者分类 |
| [掩膜与图谱](../tutorial/masks) | 查看并导出内置的脑区掩膜和图谱标签 |

**健康对照**是整个流程的核心：每例患者都与同一项目的对照比较，而不会与别的对照比较。第 1 步把它们汇总成*对照统计*，Z 值图、分类和组间比较都读取它，因而都建立在同一组对照之上。
