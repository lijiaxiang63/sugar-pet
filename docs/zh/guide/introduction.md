# SUGAR-PET 简介

SUGAR-PET 是一款专注于脑 FDG-PET **强度归一化**的桌面应用，同时也涵盖了归一化后的常见分析流程，包括个体偏离图（Z 值图 / W 值图）、帕金森综合征辅助分类以及组间统计比较。

## 为什么要做强度归一化？

FDG-PET 图像的体素值会受到注射剂量、血糖水平、体重等多种因素影响，因此不同扫描之间的原始数值无法直接对比。强度归一化的做法，就是把整幅图像除以一个**归一化因子**：

```
归一化后的图像 = 原图像 / 因子
```

软件里提供的各种方法，本质上只是估计这个因子的方式不同——有的取不受疾病影响的参考区均值，有的取全脑灰质均值，还有的通过对比图像与健康对照的比值直方图来找众数。具体怎么选，可以参考[方法怎么选](../reference/methods)。

## 注意区分两个“normalisation”

英文文献里常把空间配准和强度缩放都叫 normalisation，但它们其实是两个完全不同的步骤，在应用里也分属不同页面：

| | 空间标准化 | 强度归一化 |
| --- | --- | --- |
| 作用 | 把图像从扫描仪原始空间配准到 MNI 标准空间，让不同受试者的同一个体素对应同一个解剖位置 | 把图像除以各自的归一化因子，让不同图像之间的数值具有可比性 |
| 对应页面 | **空间标准化** | **强度归一化**及后续所有页面 |
| 依赖环境 | 需要 MATLAB 和 SPM12/SPM25 | 无需额外软件 |
| 何时使用 | 仅在图像尚未配准到 MNI 空间时需要 | 每次分析都需要 |

::: tip 你可能根本用不上 MATLAB
如果你的图像已经在 MNI 空间（无论之前是用 SPM、ANTs 还是其他工具处理的），直接跳过第一个页面即可。应用其余的所有功能都不依赖 MATLAB、SPM 或 Python。
:::

## 功能页面一览

左侧边栏按常规分析的顺序列出了各个页面：

| 页面 | 主要用途 | 是否需要参考库 |
| --- | --- | :---: |
| [空间标准化](../tutorial/spatial) | 调用 SPM 将原始空间的 PET 图像配准到 MNI 空间 | 否 |
| [强度归一化](../tutorial/normalize) | 计算归一化因子并输出归一化后的图像 | HN、iPS、iHN 需要 |
| [参考库](../tutorial/build-reference) | 将健康对照组汇总为一个文件夹（即“参考库”） | 本页面用于创建参考库 |
| [Z 值图](../tutorial/zmap) | 计算单个患者在各个体素上偏离健康对照的程度 | 是 |
| [帕金森综合征分类](../tutorial/classify) | 评估患者图像与典型代谢模式的匹配度并生成报告 | 是 |
| [组间比较](../tutorial/compare) | 对两组图像做逐体素双样本 t 检验，带多重比较校正 | HN、iPS、iHN 需要 |
| [参考簇](../tutorial/reference-cluster) | 从患者组数据中自动提取未受累的体素作为参考区 | 是 |
| [掩膜与图谱](../tutorial/masks) | 查看并导出应用内置的脑区掩膜和图谱标签 | 否 |

这其中，**参考库**是整个流程的核心。它保存了健康对照组的基准信息，建好一次之后，后续所有患者的分析都能直接调用，无需反复读取对照图像。因此，我们的教程也会从这里入手。
