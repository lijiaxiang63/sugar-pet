# 准备数据

在正式跑分析前花十分钟把数据整理规范，后面能省掉很多麻烦。一个项目需要三类输入：患者的图像、至少 3 例健康对照，以及（可选但建议提供的）年龄和性别表。

## PET 图像

* **文件格式**：NIfTI 格式（`.nii` 或 `.nii.gz`），每位受试者对应一幅静态 FDG-PET 图像。
* **图像空间**：MNI 空间或扫描仪原始空间，在“数据”页面说明是哪一种。原始空间的图像会先经过[空间标准化](../tutorial/spatial)，之后各项分析才会读取。体素大小和包围盒不限。
* **网格一致**：项目中所有图像的体素大小和矩阵维度必须一致。只要它们是用同一套流程配准的，通常自然满足。
* **关于平滑**：不要提前手动平滑图像。需要平滑的步骤（如计算因子、Z 值图或组间比较）软件内部会自动处理（默认 8 mm），而**强度归一化**输出的结果图像本身是未平滑的。如果你的图像在导入前已经平滑过，记得在界面要求填写平滑核的地方设为 `0`。

::: warning 务必逐幅检查配准质量
只依赖 PET 图像做空间标准化时，偶尔会出现配准跑偏但软件并未报错的情况。正式分析前，强烈建议用看图软件（如 MRIcroGL、FSLeyes、ITK-SNAP 或 SPM 的 Check Reg）把配准后的图像逐张看一遍，确认大脑没有变形、歪斜或被裁切。
:::

## 健康对照 {#the-healthy-controls}

每个项目都有自己的健康对照，每例患者都与它们比较，不会与别的对照比较：直方图归一化、Z 值图、分类、组间比较和参考簇都建立在同一组对照之上。别处建好的对照统计不能导入；要用其他研究的对照，请把它们的图像加入项目。对照组图像应当来自**同一台扫描仪**、采用**相同的重建参数**，并经过完全一致的预处理。

| 对照组例数 | 适用范围 |
| --- | --- |
| 少于 3 例 | 不够：软件什么都不会运行 |
| 3 ~ 9 例 | 可以估算 HN、iPS、iHN 的归一化因子，但体素级统计不够稳健 |
| 20 例以上 | 推荐用于 Z 值图和组间比较 |
| 30 例以上 | 推荐用于单病例帕金森分类 |

## 年龄和性别表（协变量） {#the-table-of-ages-and-sexes}

大脑对 FDG 的摄取会随年龄变化，男女之间也存在细微差异。提供一张记录年龄和性别的表格，就能在分析中校正这些协变量（见 [W 值](../tutorial/zmap#z-scores-or-w-scores)）。表格支持 TSV 或 CSV 格式，直接复用 BIDS 规范的 `participants.tsv` 即可：

```
participant_id	age	sex
sub-hc01	63	F
sub-hc02	58	M
sub-pt01	71	M
```

* 软件默认按 `participant_id` 匹配图像文件，例如 `sub-pt01` 会自动对应 `sub-pt01_space-MNI_pet.nii.gz`；也可以在表里加一列 `image` 来直接指定文件名。
* 软件只会读取你在界面上勾选的列。纳入校正的列必须是连续数值（如年龄），或是只有两种取值的分类变量（如 `F` 和 `M`）。
* 患者和对照组的信息可以放在同一张表里，如上面的示例所示。

## 文件命名规范

软件沿用 BIDS 风格，根据输入文件名自动生成输出文件名：

| 输入文件名 | 生成的输出文件 |
| --- | --- |
| `sub-pt01_space-MNI_pet.nii.gz` | `sub-pt01_space-MNI_desc-hn_pet.nii.gz`（HN 归一化后的图像） |
| | `sub-pt01_space-MNI_desc-hn_zmap.nii.gz`（Z 值图） |
| | `sub-pt01_space-MNI_report.html`（分类报告） |

因此，每幅输入图像都必须有唯一的文件名。如果不同文件夹下存在同名文件（例如 `a/pet.nii.gz` 和 `b/pet.nii.gz`），它们会映射到同一个输出文件名——在“空间标准化”和“帕金森综合征分类”页面，程序会直接报错并停止运行；在其他页面，后处理的结果则会覆盖先处理的结果。

## 项目文件夹

不需要自己建立任何文件夹：[项目](../tutorial/project)就是软件建立的一个文件夹，各类文件各有其位置。图像可以留在原处（项目记下它们的位置），也可以复制进项目，这样项目包含了一切，可以整体移动或分享。

```
my-study/
├── sugar-pet-project.json   软件随操作记录的内容
├── raw/                     原始空间的图像（如需要）
├── patients/                MNI 空间的患者图像
├── controls/                MNI 空间的对照图像
├── participants.tsv         所有受试者的年龄和性别
│
├── hc_reference/            对照统计                  （第 1 步）
├── normalised/              归一化图像、factors.tsv   （第 1 步）
├── zmaps/                   Z 值图或 W 值图            （第 2 步）
├── reports/                 分类报告                  （第 3 步）
├── quick/                   快速分类
├── compare/                 组间比较
└── reference_cluster.nii.gz 参考簇
```

在项目中配准的原始空间图像会写入 `patients/` 和 `controls/`。用 `sugar-pet init` 建立的研究文件夹布局相同，可以直接作为项目打开：其中的图像和填好的 `participants.tsv` 都会被纳入。
