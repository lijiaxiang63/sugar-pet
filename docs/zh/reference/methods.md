# 方法怎么选

所有强度归一化方法做的事情都一样——把整幅图像除以一个常数，区别仅仅在于这个**归一化因子**是怎么算出来的。

## 方法一览

| 应用内名称 | 命令行 `-m` | 因子的估计方式 | 是否需要对照统计 |
| --- | --- | --- | :---: |
| **直方图归一化 HN** | `hn` | 图像除以对照均值图，取比值直方图中**出现频率最高**的值 | 是 |
| 迭代直方图 iHN | `ihn` | 先做 HN，剔除低代谢体素后再重算一次 | 是 |
| 迭代比例缩放 iPS | `ips` | 先做 PS，剔除低代谢体素后再重算一次 | 是 |
| 比例缩放 PS | `ps` | 取灰质掩膜内的平均摄取 | 否 |
| SPM 全局均值 | `spm-global` | 取高于全图均值 1/8 的所有体素的均值 | 否 |
| 全脑 | `whole-brain` | 取灰质加白质的平均摄取 | 否 |
| 全小脑 | `cerebellum` | 取全小脑的平均摄取 | 否 |
| 小脑灰质 | `cerebellar-gm` | 取小脑灰质的平均摄取 | 否 |
| 脑桥 | `pons` | 取脑桥中央区域的平均摄取 | 否 |
| 深部白质 | `white-matter` | 取大脑深部白质的平均摄取 | 否 |
| 枕叶皮层 | `occipital` | 取枕叶皮层的平均摄取 | 否 |
| 感觉运动皮层 | `sensorimotor` | 取初级感觉运动皮层的平均摄取 | 否 |
| 自选区域 | `region` | 取任意指定区域（内置掩膜、外部掩膜文件或图谱标签）的平均摄取 | 否 |

## 该选哪一种？

根据 [López-González 等（2020）](https://doi.org/10.1016/j.neuroimage.2020.117229)的对比评估：

* **日常分析优先选 HN**：它不需要提前假设哪个脑区未受累，在各类数据驱动方法中表现最好。`ihn` 算出来的因子通常和 `hn` 相差无几。
* **大范围低代谢时慎用 PS**：病灶范围大时，全局均值会被整体拉低，算出来的因子偏小，结果反而让未受累的正常脑区显得“高代谢”。`ips` 可以消除绝大部分这类偏差。
* **参考区法取决于先验假设是否成立**：选中的参考区必须体积足够大，而且确实不受所研究疾病的影响。像脑桥这样体积较小的区域，信噪比通常不太理想。

## 常见疾病的参考区参考

| 疾病 | 不建议作参考区 | 通常相对保留的区域 |
| --- | --- | --- |
| 阿尔茨海默病（AD） | — | 小脑、脑桥、感觉运动皮层 |
| 多系统萎缩（MSA） | 小脑、脑桥 | 枕叶皮层 |
| 进行性核上性麻痹（PSP） | 脑桥（邻近萎缩的中脑） | 枕叶皮层、小脑 |
| 皮质基底节综合征（CBS） | 感觉运动皮层 | 枕叶皮层、小脑 |
| 路易体痴呆（DLB）、后部皮质萎缩（PCA） | 枕叶皮层 | 小脑、感觉运动皮层 |

以上只是常见规律，具体选区仍应结合你所研究疾病的病理分期和最新文献来定。

## HN 的局限性

HN、iPS 和 PS 都隐含了一个前提：**大部分**灰质是正常的。如果某种疾病导致全脑几乎所有皮层区域的摄取都弥漫性下降，这三种方法就很难看出来。遇到这种情况，建议改用深部白质参考区或[参考簇](../tutorial/reference-cluster)做一次敏感性分析。

## 推荐的研究流程

这套流程主要针对“患者组 vs. 健康对照组”的常规对比研究，设计时重点考虑了非典型帕金森综合征（如 MSA、PSP、CBS 等小脑或脑桥本身常受累的疾病）：

1. **统一预处理标准**：患者和对照尽量来自同一台扫描仪、采用相同的重建参数，走同一套空间标准化流程，并且逐幅目视检查配准质量。
2. **为项目提供对照和协变量表**，并在*其他方法的对照统计*中勾选*枕叶皮层*和*深部白质*（[数据](../tutorial/project)、[第 1 步](../tutorial/normalize)）。
3. **主分析使用 HN 做组间比较**（[组间比较](../tutorial/compare)）。
4. **个案评估使用 W 值图**（[第 2 步](../tutorial/zmap)）；诊断未明的患者可进一步生成分类报告（[第 3 步](../tutorial/classify)）。
5. **敏感性验证**：分别换用*枕叶皮层*和*深部白质*重做一遍组间比较，确认核心结论是否稳健。

**几个常见误区（建议避开）：**

* 选用了疾病本身会累及的脑区作参考区（例如 MSA 用小脑/脑桥，PSP 用脑桥，CBS 用感觉运动皮层）；
* 患者组和对照组用了不同的归一化方法；
* 两组年龄存在差异时，直接看未校正的普通 Z 值；
* 用同一批患者生成参考簇，回头再用这个参考簇去检验这批患者自己。

## 几处实现细节

* **HN**：为了避免直接取直方图最大值受分箱宽度（bin width）影响，软件会先用高斯核平滑比值直方图（即核密度估计），然后再寻找峰值。
* **为什么 iHN ≈ HN？** 低代谢体素大多落在比值直方图的左尾，离主峰很远，剔除它们几乎不会改变峰值的位置。因此两者的因子通常只差千分之几，这种抗干扰能力正是 HN 好用的原因。
* **尺度统一**：PS、iPS、HN 和 iHN 都统一标定在“健康灰质均值约为 1”的尺度上。
* **W 值计算**：在每个体素上对归一化后的对照组做协变量（如年龄、性别）的普通最小二乘回归，患者残差再除以对照组的残差标准差。
