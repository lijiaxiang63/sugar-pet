# 第 2 步：建立参考库

**页面：参考库** · 每项研究建一次即可

*参考库*其实就是一个汇总了健康对照组基准数据的文件夹，里面保存着对照组的均值图、离散程度，以及代谢随年龄和性别的变化模型。建好一次后，后续分析每位患者时都能直接调用它，不再需要反复读取原始的对照图像。

以下功能都依赖参考库：

* 任意页面中的 **HN**、**iPS**、**iHN** 归一化方法；
* [Z 值图](./zmap)、[帕金森综合征分类](./classify)和[参考簇](./reference-cluster)。

## 添加对照图像

打开**参考库**页面，向下滚动到*新建参考库*。

<Shot name="reference-controls" alt="“参考库”页面：用于新建参考库的对照" :marks="[[1, 315]]" />

1. **添加对照图像**：Ada 直接把 `study/controls/` 文件夹拖进了列表，一共 16 幅图像。所有对照图像必须都在 MNI 空间且网格一致。软件至少需要 3 例对照才能运行，但若少于 10 例左右，体素级的统计估计会不够稳健。

## 设置协变量、保存位置和选项

向下滚动页面。

<Shot name="reference-settings" alt="新建参考库的协变量、文件夹和选项" :marks="[[2, 529], [3, 717], [4, 777], [5, 'run']]" />

2. **协变量表**：点击**选择…**并选中 `participants.tsv`。表格中的列名会作为复选框出现在*校正的列*下方，勾选 **age** 和 **sex**。只有提供了协变量表，后面才能计算校正年龄和性别的 [W 值](./zmap#z-or-w)。如果手头没有协变量表，跳过这一项即可。
3. **参考库文件夹**：指定保存路径，Ada 新建并选择了 `study/hc_reference/`。
4. **当前生效的选项**：掩膜、平滑，以及额外用于 Z 值图的方法。点击**选项…**打开**设置 › 参考库**（见下文），勾选之后还想用来制作 Z 值图的参考区；勾选后这一行会显示*另可用以下方法制作 Z 值图：枕叶皮层、深部白质*，并出现**已修改 1 项**的标记。
5. 点击**建立参考库**，软件会逐一读取对照图像并完成计算。

### 新建参考库的选项 {#options}

<Shot name="settings-reference" alt="设置 › 参考库" />

* **掩膜**：用于估计归一化因子的体素范围，保持默认的**灰质**即可（与文献做法一致）。列表末尾的*掩膜文件…*可以换成你自己的 NIfTI 文件。
* **平滑 (FWHM, mm)**：保持默认的 **8** mm。只有当你的图像在导入前已经做过平滑时，才需要改成 `0`。
* **其他方法的 Z 值图**：PS、iPS、HN 和 iHN 始终可用。如果你之后还想用其他参考区（如枕叶、白质）来算 Z 值图，需要在这里提前勾选。Ada 勾选了**枕叶皮层**和**深部白质**，方便在[第 6 步](./compare#robust)做敏感性分析，同时也能让[分类](./classify)多一层交叉核对。

这些选项只对之后新建的参考库生效；已经建好的参考库保持建立时的设置不变。

::: tip 对照的因子如何估计
对照的归一化因子按**设置 › 强度归一化**里*因子*一节的方式估计（[区域统计量和估计因子前的平滑](./normalize#options)），与之后对患者图像做强度归一化时用的是同一套设置，参考库会把它记下来。默认设置（均值、自动平滑）下无需理会；如果你想改用中位数或自己设定平滑，先改好设置再建参考库，这样患者图像和对照才是同一种归一化方式，才能做 [Z 值图](./zmap)。
:::

## 查看结果

参考库建好后，回到页面顶部。

<Shot name="reference" alt="当前参考库及其对照均值图" :marks="[[6, 160], [7, 500]]" />

6. **当前参考库**：这里会更新为新建参考库的信息，包括对照例数、平滑核大小、纳入的协变量，以及支持生成 Z 值图的方法。同时，所有其他页面都会自动选用这个参考库，侧边栏底部也会显示它的名称。
7. **对照的均值图**：对照组平滑后平均图像的横断面切片。它看起来应该是一个轮廓清晰、左右对称的大脑；如果边缘发虚或出现重影，说明有些对照图像没有在 MNI 空间里对齐。图片下方的按钮通往接下来的两条路线：**前往强度归一化**开始个案分析，**前往组间比较**做组水平统计。

::: tip 打开已有的参考库
如果想切换回以前建好的参考库，点击本页面的**打开其他…**，或者直接点击侧边栏底部的当前参考库名称，然后选择对应文件夹即可。通过命令行（`sugar-pet build-reference`）生成的参考库同样可以直接打开。
:::

## 输出文件夹内容

| 文件 | 说明 |
| --- | --- |
| `template.nii.gz` | 对照组经比例缩放后的均值图（即 HN 方法中的“正常模板”） |
| `ps_std.nii.gz` | 对照组经 PS 归一化后的标准差图 |
| `hn_mean.nii.gz`、`hn_std.nii.gz` | 对照组经 HN 归一化后的均值与标准差图 |
| `mask.nii.gz` | 估计因子时所用的脑区掩膜 |
| `reference.json` | 记录对照例数、平滑核大小以及每例对照的因子等元信息 |
| `stats-<方法>_mean.nii.gz`、`…_std.nii.gz` | 在*其他方法的 Z 值图*（第 4 项）中额外勾选的方法对应的对照组均值与标准差图 |
| `model-<方法>_beta.nii.gz`、`…_sd.nii.gz` | 提供协变量表时生成，记录各体素摄取与年龄、性别的回归参数 |

请保持参考库文件夹内的文件原样，不要手动修改。如果需要增减对照或调整选项，请重新建一个参考库。

::: details 对应的命令行
```bash
sugar-pet build-reference controls/*.nii.gz -o hc_reference/ \
    --covariates participants.tsv --stats-for occipital,white-matter
```
:::
