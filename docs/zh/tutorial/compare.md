# 第 6 步：组间比较

**页面：组间比较**

这一页用来回答“患者组和对照组在哪些脑区存在代谢差异”。点击运行后，软件会一次性串联完成：用统一方法归一化两组图像、空间平滑、逐体素双样本 t 检验、多重比较校正，并自动整理出通过校正的显著团块及其解剖脑区位置。

## 操作步骤

<Shot name="compare" alt="“组间比较”页面：分组、强度归一化和协变量" :marks="[[1, 160], [2, 1027, 160], [3, 566], [4, 622], [5, 752]]" />

1. **第 1 组**：添加患者组图像（本例为 12 幅）。
2. **第 2 组**：添加对照组图像（本例为 16 幅）。统计方向固定为*第 1 组减去第 2 组*：因此把患者放在第 1 组时，**负的 T 值代表患者组代谢减低**。注意不要重复添加同一个人，检验要求样本相互独立。两个列表下方的**互换两组**可以交换第 1 组和第 2 组。
3. **方法**：主分析保持默认的**直方图归一化 HN**。
4. **参考库**：通常会自动填好（HN、iPS、iHN 方法必需）。两组图像会共用同一个参考库。
5. **协变量表**（建议提供）：选择 `participants.tsv`，并勾选 **age** 和 **sex** 纳入统计模型。这张表需要包含两组的所有受试者；如果患者和对照的信息分别保存在两张表里，界面下方会出现**第二个表格**选项，用于补充导入另一张表。

向下滚动页面。

<Shot name="compare-output" alt="输出、选项和结果的开头" :marks="[[6, 298], [7, 347], [8, 403], [9, 'run']]" />

6. **输出文件夹**：Ada 选择了 `study/compare/`。
7. **结果文件名称**：设定所有输出文件的前缀，本例设为 `patients_vs_controls`。
8. **当前生效的选项**：多重比较校正及其阈值、参与检验的体素范围，以及平滑。如果没有特殊需求，保持默认设置（*GRF 校正：体素 p < 0.001，团块 p < 0.05 · 范围：灰质 · 平滑自动*）即可；点击**选项…**会打开**设置 › 组间比较**（见[选项](#options)）。
9. 点击**开始比较**。

## 检查结果

<Shot name="compare-results" alt="组间比较的结果" :marks="[[10, 158], [11, 208], [12, 430], [13, 712]]" />

10. **结果标题下方的说明**：自动生成的一段关于多重比较校正参数的文字，可以直接参考着写进论文的方法部分。
11. **统计概要**：显示检验自由度、校正所基于的数据平滑度估计值，以及通过校正的显著团块数量。
12. **图片**：把通过校正的团块的 T 图叠加显示在模板的横断面切片上——蓝色到青色表示第 1 组低于第 2 组，红色到黄色表示高于第 2 组。选择不校正时，显示的是 |T| > 3 的未校正 T 图。
13. **团块列表**：每个显著团块占一行，包含体素数、峰值 T 值与 MNI 坐标、峰值所在脑区以及团块覆盖的主要脑区。蓝色代表负值（第 1 组低于第 2 组），红色代表正值。

## 输出文件说明

| 输出文件夹中的文件 | 说明 |
| --- | --- |
| `patients_vs_controls_T.nii.gz` | 未设阈值的原始 T 值图 |
| `ClusterThresholded_patients_vs_controls_T.nii.gz` | 仅保留通过校正的显著团块的 T 值图 |
| `ClusterReport_patients_vs_controls_T.csv` | 团块详细报告，包含大小、峰值坐标及 AAL / Harvard-Oxford 脑区标注 |
| `patients_vs_controls_factors.tsv` | 每幅图像的归一化因子明细 |
| `patients_vs_controls_mask.nii.gz` | 实际参与统计检验的体素掩膜 |
| `patients_vs_controls_beta.nii.gz`、`…_cohen_f2.nii.gz` | 回归模型系数图与效应量（Cohen's f²）图 |

## 选项 {#options}

组间比较的统计参数在**设置 › 组间比较**中设置（点击页面上的**选项…**即可打开）。

<Shot name="settings-compare" alt="设置 › 组间比较" />

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| 多重比较校正 | GRF | **GRF**：基于高斯随机场理论的团块水平校正；**FDR**：体素水平的错误发现率校正；**不校正**：仅输出原始未设阈值的 T 值图。所有检验均为双侧检验 |
| 体素水平 p 值 | 0.001 | GRF：用于形成团块的双侧阈值 |
| 团块水平 p 值 | 0.05 | GRF：团块的显著性水平 |
| q 值 | 0.05 | FDR：错误发现率（选择 FDR 时，它取代上面两个 p 值显示） |
| 检验的体素 | 灰质 | 可选用内置掩膜或自定义文件。只要任意一幅图像未覆盖到的体素都会被自动剔除 |
| 检验前的平滑 | 自动 | 默认沿用参考库的平滑核（无参考库时为 8 mm）。若图像已平滑，请填 `0` |
| 保留参与检验的图像 | 关 | 开启后会把归一化并平滑后的中间图像一并保存下来 |

## 敏感性分析：检查结果是否稳健 {#robust}

如果一个统计发现只在某一种归一化方法下才出现，那它的稳健性就值得怀疑。建议保持其他设置不变，只修改**方法**和**结果文件名称**，把组间比较再跑两遍：

1. 改用**枕叶皮层**：作为一个解剖参考区，MSA、PSP 和 CBS 通常不累及枕叶；
2. 改用**深部白质**：它不依赖“大部分灰质正常”的假设，能够检出 HN 可能漏掉的弥漫性全脑代谢下降，不过噪声相对会大一些。

如果核心结论在这几种方法下保持一致，论文中报告 HN 的结果并说明做过敏感性验证即可；如果结果随方法改变而变化，则应当如实说明这种局限性。

::: tip 论文方法部分建议写明的内容
使用的归一化方法（HN）、健康对照的例数、年龄范围和性别构成、平滑核大小（默认 8 mm）、具体的多重比较校正参数（可直接参考**结果**标题下方的说明），以及 SUGAR-PET 的版本号。
:::

::: details 对应的命令行
```bash
sugar-pet compare --group1 patients/*.nii.gz --group2 controls/*.nii.gz \
    -m hn -r hc_reference/ -o compare/ --covariates participants.tsv --name patients_vs_controls
```
:::
