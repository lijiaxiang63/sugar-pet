# 组间比较

**页面：组间比较** · 需要先完成第 1 步

这一页回答“患者在哪些脑区与对照不同”。它读取[第 1 步](./normalize)归一化后的图像，进行平滑，逐体素拟合双样本 t 检验，做多重比较校正，并列出通过校正的团块及其解剖脑区。

## 运行

<Shot name="compare" alt="“组间比较”页面" :marks="[[1, 163], [2, 204], [3, 904, 290], [4, 396], [5, 552], [6, 687], [7, 733], [8, 790], [9, 'run']]" />

1. **第 1 组 · 患者**和 2. **第 2 组 · 健康对照**：项目的两组图像，即第 1 步归一化后的结果。T 图为*第 1 组减第 2 组*，所以以患者为第 1 组时，**负的 T 值表示低代谢**。要修改图像，点**到“数据”页面修改**。
3. **互换两组**交换第 1 组和第 2 组。
4. **方法**：第 1 步的主方法；这里不会再归一化一次。要换用其他方法，在第 1 步把它设为主方法（**到“强度归一化”页面修改**）并重新运行。主分析推荐**直方图归一化 HN**。
5. **协变量**：“数据”页面选择的协变量，这里是 `participants.tsv` 中的 *age* 和 *sex*。表格必须包含两组的每一幅图像。
6. **输出位置**：项目的 `compare` 文件夹。
7. **结果文件名称**：所有输出文件的前缀，这里是 `patients_vs_controls`。
8. **当前生效的选项**：校正方法及其阈值、检验的体素和平滑。没有特殊理由时保持默认（*GRF 校正：体素 p < 0.001，团块 p < 0.05 · 灰质 · 平滑自动*）；**选项…**打开**设置 › 组间比较**（[见下文](#options)）。
9. 点击**开始比较**。

## 检查结果

<Shot name="compare-results" alt="组间比较的结果" :marks="[[10, 154], [11, 192], [12, 602], [13, 645], [14, 268, 782]]" />

10. **“结果”下方的一句话**准确说明了所用的校正，可以直接写进论文的方法部分。
11. **概要**：自由度、校正所用的数据平滑度，以及显著团块的数量。
12. **图片**在模板的横断面切片上显示通过校正的团块的 T 图：蓝色到青色表示第 1 组较低，红色到黄色表示较高。不做校正时显示 |T| > 3 的未校正 T 图。
13. **团块**：每个团块一行：体素数、峰值 T 及其 MNI 坐标、峰值所在脑区以及覆盖的脑区。蓝色峰值为负（第 1 组较低），红色为正。
14. **在访达中显示**打开 `compare` 文件夹。

## 输出文件

| `compare/` 中的文件 | 内容 |
| --- | --- |
| `patients_vs_controls_T.nii.gz` | 未设阈值的 T 图 |
| `ClusterThresholded_patients_vs_controls_T.nii.gz` | 只保留通过校正的团块的 T 图 |
| `ClusterReport_patients_vs_controls_T.csv` | 每个团块一行：大小、峰值、AAL 和 Harvard-Oxford 脑区 |
| `patients_vs_controls_factors.tsv` | 每幅图像的归一化因子 |
| `patients_vs_controls_mask.nii.gz` | 参与检验的体素 |
| `patients_vs_controls_beta.nii.gz`、`…_cohen_f2.nii.gz` | 模型系数和效应量 |

## 选项 {#options}

<Shot name="settings-compare" alt="设置 › 组间比较" />

| 选项 | 默认值 | 作用 |
| --- | --- | --- |
| 多重比较校正 | GRF | **GRF**：基于高斯随机场理论的团块水平校正。**FDR**：体素水平的错误发现率。**不校正**：只输出未设阈值的 T 图。所有检验均为双侧 |
| 体素水平 p | 0.001 | GRF：形成团块的双侧阈值 |
| 团块水平 p | 0.05 | GRF：团块的显著性 |
| q 值 | 0.05 | FDR：错误发现率（代替上面两个 p 值） |
| 检验的体素 | 灰质 | 内置掩膜或你自己的文件；任何一幅图像没有覆盖的体素都会排除 |
| 检验前的平滑 | 自动 | 与对照统计相同（尚无对照统计时为 8 mm）；图像已经平滑过时填 `0` |
| 保留参与检验的图像 | 关 | 同时写出两组归一化并平滑后的图像 |

## 检查结果是否稳健 {#check-that-the-result-is-robust}

依赖于归一化方法选择的发现是不稳健的。在第 1 步中再勾选下面的方法并运行，然后再做两次比较，每次在第 1 步换一个**主方法**，在这里换一个**结果文件名称**：

1. **枕叶皮层**：MSA、PSP 和 CBS 通常不累及的解剖参考区；
2. **深部白质**：不对灰质作任何假设，因此能显示 HN 遗漏的弥漫性减低，但噪声更大。

主要发现保持不变时，报告 HN 的结果并说明做过核对；发现改变时，如实报告。

::: tip 写进论文
请报告方法（`HN`）、对照的人数、年龄范围和性别构成、平滑（默认 8 mm）、校正（**结果**下方的那句话）以及 SUGAR-PET 的版本。
:::

::: details 对应的命令行
```bash
sugar-pet compare --group1 patients/*.nii.gz --group2 controls/*.nii.gz \
    -m hn -r hc_reference/ -o compare/ --covariates participants.tsv --name patients_vs_controls
```
:::
