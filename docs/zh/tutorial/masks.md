# 掩膜与图谱

**页面：掩膜与图谱** · 资源，不是分析步骤

这一页列出软件内置的脑区。你可以用它查看某个参考区覆盖了哪些位置、导出掩膜在看图软件中检查，或者查找自选区域要用到的标签编号。

## 内置掩膜

<Shot name="masks" alt="内置掩膜" :marks="[[1, 161]]" />

1. **掩膜列表**：每行给出名称、覆盖范围、简称（命令行和文件名中使用）以及体积。

| 掩膜 | 简称 | 用途 |
| --- | --- | --- |
| 灰质 | `gray-matter` | PS、HN、iPS、iHN；组间比较默认检验的体素 |
| 脑实质 | `parenchyma` | 全脑 |
| 全小脑 | `cerebellum` | 参考区（文献中的 RRC） |
| 小脑灰质 | `cerebellar-gm` | 参考区 |
| 脑桥 | `pons` | 参考区 |
| 深部白质 | `white-matter` | 参考区 |
| 枕叶皮层 | `occipital` | 参考区 |
| 感觉运动皮层 | `sensorimotor` | 参考区 |
| 脑干 | `brainstem` | 自选区域（文献中的 RRBS） |
| 左侧 / 右侧颞叶皮层 | `temporal-left`、`temporal-right` | 自选区域（RRTL：取病灶*对侧*） |

所有掩膜都基于 2 mm 的 MNI 网格（ICBM 2009c），使用时自动重采样到每幅图像。脑桥掩膜是一个实用的脑桥中央区，不是解剖学金标准。使用其他 MNI 模板或图谱时，请提供你自己的掩膜文件。

## 图谱标签

向下滚动页面。

<Shot name="masks-atlas" alt="CerebrA 图谱的标签" :marks="[[2, 344, 405], [3, 503], [4, 544]]" />

2. **全部导出为 NIfTI…**把所有内置掩膜导出为 NIfTI 文件，保存到你选择的文件夹，便于叠加在 MNI 模板上查看。
3. **搜索脑区**：按名称查找脑区。
4. **标签**：每个脑区的右侧和左侧各有一个编号。勾选需要的脑区，表格下方会出现一栏列出它们的编号，**用于自选区域归一化**打开强度归一化页面，以它们作为自选区域。

要手动填写编号，在[强度归一化](./normalize#a-region-of-your-own)中勾选**自选区域**，选择**图谱标签**，用英文逗号分隔填入：`34,85` 为双侧外侧枕叶皮层，`40,91` 为双侧丘脑。

::: details 对应的命令行
```bash
sugar-pet masks -o masks/     # 导出内置掩膜
sugar-pet labels              # 列出图谱标签
```
:::
