# 掩膜与图谱

**页面：掩膜与图谱** · 资源查阅页面

这一页汇总了软件内置的所有脑区掩膜和图谱标签。你可以用它来确认某个参考区具体覆盖了哪些位置、把掩膜导出到看图软件里检查，或者查询自选区域时需要用到的标签编号。

## 内置掩膜

<Shot name="masks" alt="内置掩膜及其简称和体积" :marks="[[1, 122], [2, 645]]" />

1. **掩膜列表**：每行展示了一个内置掩膜的名称、覆盖范围、简称（命令行和输出文件名中使用的标识）以及体积。
2. **全部导出为 NIfTI…**：点击后可以选择一个文件夹，把所有内置掩膜逐一导出为 NIfTI 文件，方便叠加在 MNI 模板上直观查看边界。

| 掩膜名称 | 简称 | 常见用途 |
| --- | --- | --- |
| 灰质 | `gray-matter` | PS、HN、iPS、iHN 计算；组间比较默认分析掩膜 |
| 脑实质 | `parenchyma` | 全脑范围 |
| 全小脑 | `cerebellum` | 参考区（文献中的 RRC） |
| 小脑灰质 | `cerebellar-gm` | 参考区 |
| 脑桥 | `pons` | 参考区 |
| 深部白质 | `white-matter` | 参考区 |
| 枕叶皮层 | `occipital` | 参考区 |
| 感觉运动皮层 | `sensorimotor` | 参考区 |
| 脑干 | `brainstem` | 自选区域（文献中的 RRBS） |
| 左侧 / 右侧颞叶皮层 | `temporal-left`、`temporal-right` | 自选区域（RRTL，通常选病灶**对侧**） |

所有内置掩膜均基于 MNI 空间（ICBM 2009c）的 2 mm 网格制作，使用时软件会自动将其重采样到每幅输入图像的网格上。需要注意，这里的脑桥掩膜是一个面向实用目的提取的脑桥中央区，并非严格的解剖学边界金标准；如果你的研究使用了其他版本的 MNI 模板或特定图谱，建议传入自定义的掩膜文件。

## 图谱标签

向下滚动页面，可以浏览 CerebrA 图谱的完整标签列表。

<Shot name="masks-atlas" alt="CerebrA 图谱的标签" :marks="[[3, 334], [4, 407]]" />

3. **搜索脑区**：支持按脑区英文名称快速过滤。
4. **记录编号**：每个脑区的右侧和左侧分别对应不同的编号。

使用时，回到[强度归一化](./normalize#custom-region)页面勾选**自选区域**，选择**图谱标签**，填入以英文逗号分隔的编号即可。例如输入 `34,85` 代表双侧外侧枕叶皮层，输入 `40,91` 代表双侧丘脑。

::: details 对应的命令行
```bash
sugar-pet masks -o masks/     # 导出所有内置掩膜
sugar-pet labels              # 在终端列出所有图谱标签
```
:::
