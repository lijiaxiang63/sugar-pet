# 强度归一化

**页面：强度归一化** · 个案分析第 1 步

这一步做两件事。首先，把项目的健康对照汇总成**对照统计**：每种方法下每个体素的均值和离散程度，此后患者都与它比较。然后，把项目中的每幅图像（患者和对照）除以各自的归一化因子，写出归一化图像和因子表。Z 值图、帕金森综合征分类、组间比较和快速分类都读取它写出的结果。

## 选择方法

<Shot name="normalize" alt="“强度归一化”页面：图像和方法" :marks="[[1, 109], [2, 217], [3, 450], [4, 613]]" />

1. **步骤条**：个案分析的三步（原始空间的图像前面还有空间标准化）。打勾表示该步已完成，并且仍然建立在前面的步骤之上；点击某一步可以跳过去。
2. **图像**：项目中所有 MNI 空间的图像，来自[“数据”页面](./project)。患者和对照用同样的方式归一化，二者才可比。要修改，点**到“数据”页面修改**。
3. **方法**：推荐**直方图归一化 HN**。方法分三类：
   * *数据驱动 · 与对照比较*：HN、iHN 和 iPS，把每幅图像与对照统计比较；
   * *全局*：PS、SPM 全局均值和全脑，对（几乎）全脑或全部灰质取平均；
   * *参考区*：疾病预计不会累及的某个区域的平均摄取。
4. **多选方法**仅用于对比。每种方法都从原始图像各自写出一幅图像；全小脑图像是原图除以小脑均值，而不是 HN 图像再除一次。Ada 还勾选了**全小脑**。参考区法折叠时，**参考区法：另有 7 种方法**会把它们展开。

不确定选哪种？见[方法怎么选](../reference/methods)。

### 自选区域 {#a-region-of-your-own}

勾选**自选区域**后会出现一个卡片，有三种方式指定区域：

| 区域来源 | 需要提供 |
| --- | --- |
| 内置掩膜 | 一个[内置掩膜](./masks)，例如*脑干* |
| 掩膜文件 | 你自己的 MNI 空间 NIfTI 文件，体素值 > 0 的部分为区域 |
| 图谱标签 | CerebrA 标签编号，例如 `34,85` 表示双侧外侧枕叶皮层 |

自选区域会生成归一化图像，但不能生成 Z 值图：没有它的对照统计。

## 对照统计

向下滚动页面。

<Shot name="normalize-controls" alt="主方法和对照统计" :marks="[[5, 226], [6, 298], [7, 468], [8, 524]]" />

5. **主方法**：勾选多种方法时出现。帕金森综合征分类、组间比较和快速分类都用它。默认是 HN。
6. **对照统计**：汇总了多少例对照、汇总时的平滑（默认 8 mm），以及建模的协变量（“数据”页面有协变量表时为 *age* 和 *sex*）。首次运行前，这里会说明运行时先汇总对照。
7. **可制作 Z 值图的方法**：统计中包含的方法：PS、iPS、HN 和 iHN 始终包含，加上这里勾选的方法和设置中勾选的方法（见下文）。
8. **保存位置**：项目的 `hc_reference` 文件夹。**在访达中显示**打开它。

对照统计不需要单独运行。只要对照、对照图像文件或对照统计的设置自上次以来有变化，这一步在归一化图像之前会先重新汇总对照；如果只是协变量表变了，归一化图像依然有效，改由 [Z 值图](./zmap)重新汇总对照。需要重新汇总时，页面上会有提示。

<Shot name="normalize-output" alt="对照的均值图、选项和输出" :marks="[[9, 366], [10, 414], [11, 506], [12, 558], [13, 783, 861]]" />

9. **对照的均值图**：对照均值图像的横断面切片。它应当是清晰、对称的脑；边缘模糊或有双重轮廓，说明有些对照在 MNI 空间没有对齐好。
10. **对照统计的选项**：掩膜、平滑，以及额外保存统计的方法。**选项…**打开**设置 › 对照统计**（[见下文](#control-statistics-options)）。
11. **输出位置**：项目的 `normalised` 文件夹，每组一个子文件夹，以及 `factors.tsv`。
12. **归一化的选项**：默认值（*区域均值 · 目标值 1 · 平滑自动*）适用于大多数研究。**选项…**打开**设置 › 强度归一化**（[见下文](#options)）。
13. 点击**开始强度归一化**。完成后，旁边会出现**下一步：Z 值图**。

## 检查结果

<Shot name="normalize-results" alt="因子的图表和表格" :marks="[[14, 232], [15, 485], [16, 459, 782]]" />

14. **因子图表**：每种方法一条线，每幅图像一个点，先患者后对照。两组的因子应当在同一范围内。某幅图像的因子明显偏离，或两条线不平行，都值得再看一眼；鼠标悬停可以读取数值。
15. **表格**：每幅图像和每种方法一行，并注明组别：
    * *因子*：图像除以的数值；
    * *体素数*：估计因子用到的体素数；
    * *剔除比例*：iPS 和 iHN 作为异常剔除的体素比例。
16. **打开 factors.tsv** 打开该表；**在访达中显示**打开文件夹。

## 输出文件

| 文件 | 内容 |
| --- | --- |
| `hc_reference/` | 对照统计（见[输出文件一览](../reference/outputs#control-statistics)） |
| `normalised/patients/sub-pt01_space-MNI_desc-hn_pet.nii.gz` | 患者图像除以其 HN 因子：每幅图像每种方法一个（`desc-cerebellum`、`desc-ps` …） |
| `normalised/controls/…` | 对照的同类文件 |
| `normalised/factors.tsv` | 每幅图像每种方法一行：组别、因子、体素数、剔除比例 |

归一化图像**没有平滑**：每幅都是输入图像除以一个数。用 HN、PS、iPS 和 iHN 时，健康灰质约为 1。

::: warning 在 SPM 或其他软件中使用这些图像
请在统计软件中关闭全局缩放（SPM 中的比例缩放和 ANCOVA 都要关）：图像已经归一化过，再缩放一次会抵消你所选的方法。
:::

## 选项 {#options}

这一步的选项在**设置 › 强度归一化**中（页面上的**选项…**会打开它）。选项保存在项目中，该部分底部的**恢复默认设置**可以恢复默认值。

<Shot name="settings-normalize" alt="设置 › 强度归一化" />

| 选项 | 默认值 | 作用 |
| --- | --- | --- |
| **因子** | | |
| 区域统计量 | 均值 | 区域取均值还是中位数，用于参考区法和 PS |
| 目标值 | 1 | 参考在输出中取的值，例如 `50` 表示“全局均值 = 50” |
| 估计因子前的平滑 | 自动 | HN、iPS 和 iHN 用对照统计的平滑，其他方法不平滑；只用于估计因子 |
| **输出** | | |
| 保存掩膜 | 关 | 同时保存估计每个因子所用的体素 |
| **迭代方法** | | |
| 剔除体素的 p 值 | 0.01 | iPS 和 iHN：与对照差异达到该未校正 p 值的体素被剔除 |
| 剔除范围 | 仅低代谢 | iPS 和 iHN：只剔除低代谢体素（同原文），或高代谢体素也剔除 |
| 重新估计次数 | 1 | iPS 和 iHN：因子重新估计的次数 |
| iPS 用普通均值 | 关 | 按原文公式计算，而不是相对对照模板的均值 |

对照的因子也按*区域统计量*和*估计因子前的平滑*估计，所以修改这两项后，下次运行会重新汇总对照。

### 对照统计 {#control-statistics-options}

<Shot name="settings-controls" alt="设置 › 对照统计" />

* **掩膜**：估计因子所用的体素，默认是灰质（同原文）。列表末尾的*掩膜文件…*可以选择你自己的 NIfTI 文件。
* **平滑 (FWHM, mm)**：计算统计量之前施加的平滑，默认 8 mm。图像已经平滑过时填 `0`。
* **其他方法的对照统计**：页面上勾选的方法始终会保存统计，Z 值图不需要在这里再勾。在这里勾选的方法会额外保存统计：**深部白质**为分类增加一种不依赖灰质的交叉验证，参考区则可用于组间比较的[敏感性分析](./compare#check-that-the-result-is-robust)。

::: warning 运行后修改设置，需要重新运行这一步
Z 值图和帕金森综合征分类读取这一步写出的图像，不会再归一化一次。所以运行后修改这里的设置，该部分顶部会出现提示，离开设置窗口时软件会再提醒一次，后面的步骤也会等它重新运行。（*迭代方法*的选项只在这一步用了 iPS 或 iHN 时才算数。）
:::

::: details 对应的命令行
```bash
sugar-pet build-reference controls/*.nii.gz -o hc_reference/ --covariates participants.tsv
sugar-pet normalize patients/*.nii.gz -m hn,cerebellum -r hc_reference/ -o normalised/
```
:::
