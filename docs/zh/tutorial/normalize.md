# 第 3 步：强度归一化

**页面：强度归一化**

这个页面的任务是计算每幅图像的归一化因子，并输出除以因子后的图像以及一份因子汇总表。如果你需要直接拿到归一化后的 NIfTI 图像（比如导入其他统计软件里分析），就可以用这一页。

::: tip 这一步可以跳过
如果你只需要做[Z 值图](./zmap)、[帕金森综合征分类](./classify)或[组间比较](./compare)，这些页面都会在后台自动完成归一化，不需要先在这里跑一遍。
:::

## 添加图像并选择方法

<Shot name="normalize" alt="“强度归一化”页面：图像和方法" :marks="[[1, 163], [2, 492], [3, 650]]" />

1. **添加图像**：导入 MNI 空间的图像。Ada 添加了 `study/patients/` 下的六位患者。
2. **选择归一化方法**：通常推荐勾选**直方图归一化 HN**（需要用到[第 2 步](./build-reference)建好的参考库）。页面将方法分成了三类：
   * *数据驱动*：HN、iHN、iPS，通过与健康对照比较来确定因子；
   * *全局*：PS、SPM 全局均值、全脑，直接取全脑或全灰质的均值；
   * *参考区*：取某个不受疾病影响的特定脑区均值。
3. **支持同时多选**：你可以一次勾选多种方法做对比，每多选一种方法，每幅图像就会多输出一份对应的结果。Ada 在这里顺便多选了一个**全小脑**。

拿不准该用哪种方法？可以参考[方法怎么选](../reference/methods)。

### 自选区域 {#custom-region}

如果勾选了**自选区域**，下方会展开一张配置卡片，支持通过三种方式指定参考区：

| 区域来源 | 填写说明 |
| --- | --- |
| 内置掩膜 | 从下拉列表中挑选一个[内置掩膜](./masks)，例如*脑干* |
| 掩膜文件 | 上传自己的 MNI 空间 NIfTI 掩膜文件，所有大于 0 的体素将作为参考区 |
| 图谱标签 | 填写 CerebrA 图谱的标签编号（英文逗号分隔），例如 `34,85` 表示双侧外侧枕叶皮层 |

## 设置输出并运行

向下滚动页面。

<Shot name="normalize-results" alt="参考库、输出文件夹和结果" :marks="[[4, 278], [5, 335], [6, 405], [7, 'run'], [8, 487], [9, 784]]" />

4. **参考库**：如果刚做完第 2 步，这里会自动填好。只有 HN、iPS 和 iHN 需要用到参考库。
5. **输出文件夹**：Ada 选择了 `study/normalised/`。
6. **选项**：一般保持默认即可，各参数的具体含义见[下文](#options)。
7. 点击**开始强度归一化**。
8. **查看结果**：表格会按“图像 × 方法”逐行列出计算结果：
   * *因子*：原图像除以的数值；
   * *体素数*：参与估计因子的体素总数；
   * *剔除比例*：在 iPS 和 iHN 中，因被判定为异常而被剔除的体素占比。
9. 点击**打开 factors.tsv** 可以直接查看保存的因子表，点击**在访达中显示**则打开输出目录。

## 输出文件说明

输出文件夹里会生成以下文件：

| 文件 | 说明 |
| --- | --- |
| `sub-pt01_space-MNI_desc-hn_pet.nii.gz` | 除以归一化因子后的图像；文件名中的 `desc-<方法>` 标明了所用的方法（如 `desc-cerebellum`、`desc-ps`） |
| `factors.tsv` | 汇总表，记录每幅图像在每种方法下的因子、体素数和剔除比例 |

这里输出的归一化图像**没有经过平滑**，本质上就是原图除以一个常数。如果使用的是 HN、PS、iPS 或 iHN，输出图像中健康灰质的平均摄取值大约为 1。

::: warning 导出到 SPM 等软件做统计时的注意事项
如果你打算把这里输出的图像拿去 SPM 等其他统计软件里做分析，**请务必关闭那些软件里的全局缩放（global scaling）选项**（例如在 SPM 中不要选 proportional scaling，也不要选 ANCOVA）。因为图像已经在这里完成归一化了，再缩放一次反而会把之前的效果抵消掉。
:::

## 高级选项说明 {#options}

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| 区域统计量 | 均值 | 计算参考区或 PS 的因子时，取均值还是中位数 |
| 目标值 | 1 | 控制输出图像的整体尺度，例如设为 `50` 时，参考区均值会被缩放到 50 |
| 估计因子前的平滑 | 自动 | HN、iPS、iHN 默认沿用参考库的平滑核，其余方法不平滑（仅影响因子估计，不影响输出图像） |
| 剔除体素的 p 值 | 0.01 | iPS 和 iHN 中，与对照相比未校正 p 值小于该阈值的体素会被剔除 |
| 剔除范围 | 仅低代谢 | iPS 和 iHN 中，选择仅剔除低代谢体素（原文做法），还是连同高代谢体素一并剔除 |
| 重新估计次数 | 1 | iPS 和 iHN 的迭代次数 |
| iPS 用普通均值 | 关 | 开启后按原文的字面公式直接取受试者剩余体素的均值，而不除以对照模板在相同体素上的均值 |
| 输出归一化图像 | 开 | 关闭后只计算并输出 `factors.tsv`，不写入图像文件 |
| 保存掩膜 | 关 | 开启后会额外保存估计每个因子时实际用到的体素掩膜 |

::: details 对应的命令行
```bash
sugar-pet normalize patients/*.nii.gz -m hn,cerebellum -r hc_reference/ -o normalised/
```
:::
