# 建立项目

**页面：起始页，然后是“数据”**

SUGAR-PET 每次处理一个**项目**。项目就是一个文件夹：里面有图像、各项分析写出的所有结果，以及一个文件 `sugar-pet-project.json`，记录了项目的图像、你在每个页面上的选择、各项分析的选项，以及每一步最近一次运行的结果。这个文件会随着操作自动写入，不需要手动保存；再次打开项目时，一切都停在你离开时的样子，结果也在。

## 新建或打开项目

没有打开项目时，软件显示起始页。

<Shot name="welcome" alt="起始页" :marks="[[1, 340, 321], [2, 468, 321], [3, 268, 412]]" />

1. **新建项目…**：建立一个项目（见下文）。
2. **打开项目…**：选择项目文件夹打开。把项目文件夹拖到窗口上也能打开。
3. **最近的项目**：点击即可打开。暂时无法访问的项目（例如所在的移动硬盘没有接上）会注明；**×** 把项目从列表中移除，不会动它的文件夹。

旧版本软件建立的研究文件夹（用 `sugar-pet init` 或以前的“研究文件夹”页面创建）也会列在这里，打开时自动变成项目：`patients/` 和 `controls/` 里的图像以及填好的 `participants.tsv` 都会被纳入。

<Shot name="new-project" alt="新建项目的表单" :marks="[[4, 282, 305], [5, 282, 378], [6, 282, 434], [7, 735, 532]]" />

4. **名称**：项目的名称，也是项目文件夹的名称。
5. **存放位置**：项目文件夹建在哪个文件夹下。
6. **项目文件夹之外的图像**：选*留在原处*，软件只记下图像的位置，不会复制，但图像不能挪走；选*复制进项目*，图像会复制到项目文件夹里，这样项目包含了一切，可以整体移动或分享。之后可以在“数据”页面修改，对此后添加的图像生效。
7. **创建项目**：建立项目文件夹，包括[下文](#what-the-project-folder-holds)列出的子文件夹和一份只有表头的 `participants.tsv`，然后在“数据”页面打开项目。

## “数据”页面 {#the-data-page}

“数据”是项目的第一个页面，也是唯一添加图像的地方：其他页面都从这里读取图像。

<Shot name="data" alt="“数据”页面" :marks="[[8, 147], [9, 191], [10, 338], [11, 411], [12, 494], [13, 649, 494], [14, 'run']]" />

8. **名称**：项目在软件中显示的名称，不必和文件夹同名。
9. **项目文件夹**：项目所在的位置。**在访达中显示**打开它，**关闭项目**回到起始页。
10. **图像所在的空间**：已经配准过的图像（用 SPM、ANTs 或其他工具）选 *MNI 空间*；直接来自扫描仪的选*原始空间*。原始空间的图像要先经过[空间标准化](./spatial)，其他页面才会读取它们；这需要 MATLAB 和 SPM。Ada 的图像在原始空间。
11. **项目文件夹之外的图像**：同新建项目时。
12. **患者**：每例患者一幅 FDG-PET 图像。把文件或整个文件夹拖到列表上，或用**添加文件…**和**添加文件夹…**。项目自己的 `patients/` 文件夹里有图像时，点击**加载项目的 patients/** 一次全部加入。
13. **健康对照（至少 3 例）**：添加方式相同。每例患者都与这组对照比较，不会用别的对照：Z 值图、分类和组间比较都建立在它们之上。不足 3 例时什么都不能运行；少于 10 例左右时，逐体素统计不够可靠（见[准备数据](../guide/prepare-data#the-healthy-controls)）。同一幅图像只能属于一组。
14. 底部的状态栏说明项目里有什么，或者还缺什么；**下一步**进入下一个页面。

超过 8 幅图像的列表会出现筛选框；行末的 **×** 移除一幅图像，**清空**移除整个列表。从列表中移除图像不会删除文件。

## 年龄和性别 {#age-and-sex}

向下滚动页面。

<Shot name="data-covariates" alt="项目的协变量表" :marks="[[15, 679], [16, 734]]" />

15. **协变量表**（可选，建议提供）：一份 TSV 或 CSV 文件，包含项目中每幅图像（患者和对照）的年龄和性别，例如填好之后的项目自带 `participants.tsv`（**使用 participants.tsv** 直接选中它）。表格按 `image` 或 `participant_id` 列与图像对应，见[准备数据](../guide/prepare-data#the-table-of-ages-and-sexes)。
16. **校正的列**：默认是 *age* 和 *sex*。有了协变量表，对照统计会对年龄和性别对摄取的影响建模（W 值，见[第 2 步](./zmap#z-scores-or-w-scores)），组间比较也会校正它们。

表格在磁盘上有改动时软件会重新读取，所以项目打开时也可以用其他程序填写它。

## 项目文件夹里有什么 {#what-the-project-folder-holds}

| 文件夹或文件 | 由谁写入 |
| --- | --- |
| `sugar-pet-project.json` | 软件，随操作自动写入 |
| `raw/` | 无：如果需要，可以放原始空间图像 |
| `patients/`、`controls/` | 你，或者[空间标准化](./spatial)（配准后的图像写在这里） |
| `participants.tsv` | 你 |
| `hc_reference/` | [强度归一化](./normalize)：对照统计 |
| `normalised/` | [强度归一化](./normalize) |
| `zmaps/` | [Z 值图](./zmap) |
| `reports/` | [帕金森综合征分类](./classify) |
| `quick/` | [快速分类](./quick)，每例患者一个文件夹 |
| `compare/` | [组间比较](./compare) |
| `reference_cluster.nii.gz` | [参考簇](./reference-cluster) |

项目文件夹中的文件按它们在文件夹里的相对位置记录，所以包含了图像的项目可以整体移动，或在另一台电脑上打开。

::: details 对应的命令行
命令行没有项目文件，但会建立相同的文件夹：

```bash
sugar-pet init study/
```
:::
