# 快速分类

**页面：快速分类** · 位于侧栏“项目之外” · 需要先完成第 1 步

项目分析完成之后，门诊又来了一位新患者。这一页用本项目的健康对照为这一例图像分类，方法与项目自己的患者完全相同，但**不把它加入项目**：它不属于患者列表，项目的任何一步都不会改变，项目文件也不记录它。

这例图像经过与患者相同的流程：

1. 用 SPM 和[空间标准化](./spatial)的设置配准到 MNI 空间（已在 MNI 空间则跳过）；
2. 用[第 1 步](./normalize)的**主方法**和项目的设置做强度归一化；
3. 与项目的**对照统计**比较生成偏离图，同[第 2 步](./zmap)：提供年龄和性别时为 W 值；
4. 按[帕金森综合征分类](./classify)的设置分类。

在这里为项目自己的某例患者分类，结果与第 3 步对它的结论完全一致。

::: warning 辅助决策，不是诊断
注意事项与[帕金森综合征分类](./classify)相同：请结合临床表现、MRI 和多巴胺转运体显像解读结果。
:::

## 开始之前

* 项目的第 1 步已按当前设置完成：本页沿用它的方法、设置和对照统计。对照统计需要重新汇总时（例如协变量变了），页面会说明先运行哪一步。
* 原始空间的图像需要先[设置好 SPM 与 MATLAB](./spatial#set-up-spm-and-matlab-once)。

## 运行

<Shot name="quick" alt="“快速分类”页面" :marks="[[1, 161], [2, 217], [3, 273], [4, 329], [5, 461], [6, 502], [7, 543], [8, 'run']]" />

1. **PET 图像**：患者的图像，一个 NIfTI 文件。Ada 从门诊的文件夹中选了 `sub-new01_pet.nii.gz`。
2. **图像所在的空间**：*原始空间*（默认）会先配准；*MNI 空间*则直接使用，此时它必须与项目图像的网格一致。
3. **age** 和 4. **sex**：对照统计建模的协变量，只有项目有协变量表时才显示。全部填写得到 W 值图，全部不填得到普通 Z 值图。
5. **方法**：第 1 步的主方法，开启交叉验证时还有用于核对的归一化方法。要修改，点**查看第 1 步**。
6. **健康对照**：患者与多少例对照比较。
7. **输出位置**：项目文件夹中的 `quick/<图像名>`，它不属于项目。
8. 点击**开始分类**。进度条先显示配准，再显示分类。

## 检查结果

<Shot name="quick-results" alt="快速分类的结果" :marks="[[9, 200], [10, 953, 209], [11, 270], [12, 680]]" />

9. **结论**：解读方式同[帕金森综合征分类](./classify#reading-the-conclusion)，附有置信度和六种模式的得分条。
10. **打开报告**在浏览器中显示报告。
11. **最低 W 值**和 **W < −2 的脑内体素**，同[第 2 步](./zmap#check-the-results)的表格，以及所用方法。
12. **偏离图**显示在配准后图像的横断面切片上：蓝色到青色表示摄取低于对照，红色到黄色表示高于对照。

向下滚动页面。

<Shot name="quick-warp" alt="需要检查的配准结果" :marks="[[13, 359], [14, 742], [15, 268, 782]]" />

13. 对于在这里配准的图像，**采信偏离图之前请先检查配准**：仅凭 PET 配准可能失败却不报错。
14. **配准后的图像**叠加了模板的脑轮廓：脑应当填满轮廓。
15. **在访达中显示**打开这例图像的文件夹。

选择另一幅图像，或修改空间或协变量，会清除结果；已运行生成的文件仍保留在文件夹中。同名图像再次分类会覆盖它的文件夹。

## 输出文件

在 `quick/sub-new01/` 中：

| 文件 | 内容 |
| --- | --- |
| `sub-new01_space-MNI_pet.nii.gz` | 配准到 MNI 空间的图像（仅原始空间图像） |
| `sub-new01_space-MNI_desc-hn_pet.nii.gz` | 用主方法归一化的图像 |
| `sub-new01_space-MNI_desc-hn_wmap.nii.gz` | W 值图（无协变量时为 `_zmap`） |
| `sub-new01_report.html` | 报告 |
| `sub-new01_classification.json` | 报告中的所有数值 |

::: details 对应的命令行
```bash
sugar-pet spatial-norm sub-new01_pet.nii.gz -o quick/ --spm-path /path/to/spm12
sugar-pet classify quick/sub-new01_space-MNI_pet.nii.gz -r hc_reference/ -o quick/ --lang zh
```
:::
