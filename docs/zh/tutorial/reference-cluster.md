# 第 7 步：参考簇

**页面：参考簇** · 进阶 · 需要参考库

除了直接从脑图谱里挑选参考区，还有一种数据驱动的做法：让患者组自己的数据告诉我们哪些体素没有受到疾病影响（[Yakushev 等，2009](https://doi.org/10.1016/j.neuroimage.2008.07.015)）。

背后的原理很直观：在做完比例缩放（PS）之后，病灶区域的低代谢会把全脑均值拉低，从而导致那些真正未受累的正常脑区在统计上反而显得“相对高代谢”。把这些显得高代谢的体素提取出来，就能作为新的参考区使用。

::: warning 切忌循环论证
参考簇是从特定这批患者的数据里算出来的，如果再用这个参考簇去把同一批患者和对照组做比较，就属于循环论证（double dipping）。正确的做法是用另一批独立患者来提取参考簇，或者采用交叉验证。
:::

## 操作步骤

<Shot name="cluster" alt="填好的“参考簇”页面" :marks="[[1, 120], [2, 432], [3, 480], [4, 528], [5, 576]]" />

1. **添加患者组图像**：至少需要 2 幅图像，且网格必须一致。
2. **确认参考库**：用于对比的健康对照基准；完成[第 2 步](./build-reference)后这里会自动填好。
3. **p 值**：单侧未校正检验的 p 值阈值，默认 0.001。
4. **最小团块体积**：小于该体积（单位 mL）的零散连通团块会被过滤掉，默认 1 mL。
5. **掩膜保存为**：指定输出掩膜的文件路径，例如 `study/reference_cluster.nii.gz`。

向下滚动页面，点击**查找参考簇**。

<Shot name="cluster-results" alt="找到的参考簇" :marks="[[6, 'run'], [7, 588], [8, 636]]" />

6. 点击**查找参考簇**。
7. **查看结果**：页面会显示提取出的参考簇总体积及保存路径。建议把生成的掩膜文件叠加到 MNI 模板上实际看一眼——如果只剩下寥寥几毫升、或者位置落在脑室/边缘等奇怪的地方，说明它并不适合作为参考区。
8. 点击**用该区域做强度归一化**，软件会自动跳转到[强度归一化](./normalize)页面，并帮你勾选好*自选区域*、填好刚生成的掩膜文件，你只需要导入待处理的图像即可直接运行。

::: details 对应的命令行
```bash
sugar-pet reference-cluster patients/*.nii.gz -r hc_reference/ -o reference_cluster.nii.gz
sugar-pet normalize others/*.nii.gz -m region --mask reference_cluster.nii.gz -o normalised/
```
:::
