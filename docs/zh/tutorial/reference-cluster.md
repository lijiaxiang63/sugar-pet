# 参考簇

**页面：参考簇** · 进阶 · 需要先完成第 1 步

除了图谱中预先定义的区域，也可以由一组患者的数据找出疾病未累及的体素作为参考区（[Yakushev 等，2009](https://doi.org/10.1016/j.neuroimage.2008.07.015)）。

按全局均值做比例缩放后，未受累的区域相对对照会显得*高*代谢，因为低代谢区域把全局均值拉低了。患者对对照的 t 检验能找出这些体素，用作参考区。

::: warning 避免循环分析
参考簇来自你提供的患者。再用这个参考簇比较同一批患者和对照是循环分析：请用另一组患者样本得出参考簇，或者做交叉验证。
:::

## 运行

<Shot name="cluster" alt="“参考簇”页面" :marks="[[1, 163], [2, 298], [3, 339], [4, 432], [5, 'run']]" />

1. **患者组**：项目的患者，至少 2 例，网格相同。要修改，点**到“数据”页面修改**。
2. **健康对照**：第 1 步汇总的对照统计，患者与之进行检验。
3. **掩膜保存为**：项目文件夹中的 `reference_cluster.nii.gz`。
4. **当前生效的选项**：检验的阈值。**选项…**打开**设置 › 参考簇**，有两个选项：
   * *p 值*：单侧，未校正（默认 `0.001`）；
   * *最小团块体积 (mL)*：更小的连通团块会被舍弃（默认 `1` mL）。
5. 点击**查找参考簇**。

## 检查结果

<Shot name="cluster-results" alt="找到的参考簇" :marks="[[6, 332], [7, 742], [8, 354, 782]]" />

6. **结果**：参考簇的体积和掩膜的保存位置。
7. **图片**在模板的横断面切片上用橙色显示参考簇。请检查它的位置：位置出人意料、只有几 mL 的参考簇不是可靠的参考区。
8. **用该区域做强度归一化**打开[强度归一化](./normalize)，勾选*自选区域*并选中这个掩膜。

::: details 对应的命令行
```bash
sugar-pet reference-cluster patients/*.nii.gz -r hc_reference/ -o reference_cluster.nii.gz
sugar-pet normalize others/*.nii.gz -m region --mask reference_cluster.nii.gz -o normalised/
```
:::
