# 第 1 步：空间标准化

**页面：空间标准化** · 可选 · 需要 MATLAB 和 SPM

这一步的作用是把图像从扫描仪原始空间配准到 MNI 标准空间。**如果你的图像已经在 MNI 空间**（无论之前是用什么工具做的配准），**请直接跳过这一步**，进入[第 2 步](./build-reference)。

## 准备工作

* 本机已安装 **MATLAB**（应用会自动查找）。
* 已下载 **SPM12 或 SPM25**（只需知道 `spm.m` 所在的文件夹路径，不必手动将其添加到 MATLAB Path 中）。
* 待处理的图像为原始空间的 FDG-PET 图像，无需配套的 MRI 结构像。

## 设置 SPM 与 MATLAB（只需一次） {#setup}

SPM 和 MATLAB 不在页面上设置，而是在设置窗口里，设好一次后应用会一直记住。在“空间标准化”页面的 **SPM 与 MATLAB** 一行点击**设置…**（设好后按钮变为**更改…**），或者自己打开**设置 › 空间标准化**。

<Shot name="settings-spatial" alt="设置 › 空间标准化" />

* **SPM 文件夹**：点击**选择…**，指定 `spm.m` 所在的目录。如果选的文件夹不是 SPM12 或 SPM25，应用会给出提示。
* **MATLAB**：如果应用找到了 MATLAB，名称下方会显示找到的位置，无需任何操作；否则点击**选择…**手动指定 MATLAB 程序（截图中即为手动指定的情况）——macOS 上选 MATLAB 应用，Windows 和 Linux 上选 `bin/matlab`。
* **PET 模板**（一般无需改动）：默认使用 SPM 自带的 PET 模板。如果你手头有同批已配准健康对照的均值图，用它作为模板往往能配得更准。
* **MATLAB 进程数**（一般无需改动）：把图像分给多个 MATLAB 进程并行处理。进程越多速度越快，但内存占用也会相应增加。

改动会即时保存，设置窗口可以关掉，也可以一直开着。

## 操作步骤

<Shot name="spatial" alt="填好的“空间标准化”页面" :marks="[[1, 160], [2, 476], [3, 533], [4, 592], [5, 'run']]" />

1. **添加原始空间的图像**：将文件拖入列表，或点击**添加文件…** / **添加文件夹…**。Ada 在这里导入了 `study/raw/` 下的六幅图像。如果输入的是 4D 动态图像，程序会自动按时间维取平均。
2. **确认 SPM 与 MATLAB**：出现绿色对勾并显示两者的路径，说明都已设好。如果这一行显示的是**设置…**，请先完成[上面的设置](#setup)。
3. **选择输出文件夹**：Ada 将其设为 `study/patients/`。配准后的图像统一为 2 mm 各向同性体素，命名格式为 `sub-pt01_space-MNI_pet.nii.gz`。
4. **当前生效的选项**：这一行显示所用的模板和 MATLAB 进程数；点击**选项…**会打开**设置 › 空间标准化**，可在那里修改。
5. 点击**开始空间标准化**，下方状态栏会实时显示已完成的数量。

## 检查结果

<Shot name="spatial-results" alt="空间标准化的结果" :marks="[[6, 135], [7, 584], [8, 784]]" />

6. **逐幅目视检查**：图片显示的是一幅配准后图像的横断面切片，上面叠加了模板的脑轮廓——脑组织应当正好填满轮廓。纯 PET 配准在个别情况下可能出现大脑歪斜、缩放异常或局部被裁切，且软件不会报错；这类图像一旦混入后续分析，会直接影响结果，所以进入下一步前务必把每一幅都看一遍。点击图片上方的箭头可以逐幅切换。
7. **查看结果列表**：表格中会列出每幅输入图像及其对应的输出文件，点击某一行即可显示该图像。如果某一行的输出显示为红色的**失败**，说明该图像配准失败，具体报错原因会显示在表格下方。
8. 确认无误后，把图像交给下一个页面：患者图像点击**用于强度归一化**，对照图像点击**用于建立参考库**，软件会跳转过去并把这些图像填进列表；也可以点击**在访达中显示**直接查看生成的文件。

::: tip 对照组也用同样流程
健康对照组的图像同样需要经过这一步（Ada 将它们输出到了 `study/controls/`）。请确保患者和对照组使用的是完全一致的空间标准化流程。
:::

## 后台原理说明

在后台，软件会先围绕头部区域裁剪图像、将坐标原点移至大脑中心，再调用 MATLAB 运行 SPM 的 “Old Normalise” 模块和 PET 模板进行配准。当然，你也可以用自己习惯的其他工具（如带 MRI 辅助的 SPM 配准或 ANTs）来做空间标准化，只要结果在 MNI 空间，就不会影响后续步骤。

::: details 对应的命令行
```bash
sugar-pet spatial-norm raw/*_pet.nii.gz -o patients/ --spm-path /path/to/spm12 --jobs 4
```
:::
