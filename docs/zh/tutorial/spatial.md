# 空间标准化

**页面：空间标准化** · 仅限原始空间的图像 · 需要 MATLAB 和 SPM

这一页把项目的图像从扫描仪原始空间配准到 MNI 空间。只有“数据”页面选择了*原始空间*时，侧栏才有这一页；图像已在 MNI 空间（无论用什么工具配准）时，直接进入[强度归一化](./normalize)。

## 开始之前

* 已安装 **MATLAB**（软件会自动查找）。
* 已下载 **SPM12 或 SPM25**。只需要知道包含 `spm.m` 的文件夹，不必把它加入 MATLAB 的路径。
* 图像是原始空间的 FDG-PET，不需要结构 MRI。

## 设置 SPM 与 MATLAB（只需一次） {#set-up-spm-and-matlab-once}

SPM 和 MATLAB 在设置里配置，而不是在页面上，软件对所有项目记住它们。在页面上点击 **SPM 与 MATLAB** 一行的**设置…**（配置好后显示为**更改…**），或自己打开**设置 › 空间标准化**。

<Shot name="settings-spatial" alt="设置 › 空间标准化" />

* **SPM 文件夹**：选择包含 `spm.m` 的文件夹。不是 SPM12 或 SPM25 时软件会提示。
* **MATLAB**：找到了 MATLAB 时这里显示它的名称，无需操作。否则请选择 MATLAB 程序：macOS 上是 MATLAB 应用，Windows 和 Linux 上是 `bin/matlab`。
* **PET 模板**（很少需要改）：不选择时使用 SPM 自带的 PET 模板。用你自己配准后的对照的均值图往往更合适。
* **MATLAB 进程数**（很少需要改）：图像分给这么多个并行的 MATLAB 进程处理。越多越快，也越占内存。

## 运行

<Shot name="spatial" alt="“空间标准化”页面" :marks="[[1, 109], [2, 234], [3, 409], [4, 467], [5, 520], [6, 755, 861]]" />

1. **步骤条**：原始空间的项目里，空间标准化排在个案分析之前，即*第 1 步之前*：第 1 步只读取它配准后的图像。打勾表示该步已完成。
2. **图像**：[“数据”页面](./project)的患者和对照，以及各有多少已经配准。要修改，点**到“数据”页面修改**。
3. **SPM 与 MATLAB**：绿色勾和两个路径表示都已配置好。如果这一行显示**设置…**，请先完成[上面的设置](#set-up-spm-and-matlab-once)。
4. **输出位置**：配准后的图像以 2 mm 体素写入项目的 `patients/` 和 `controls/` 文件夹，命名如 `sub-pt01_space-MNI_pet.nii.gz`。4D 图像会先在时间上取平均。
5. **当前生效的选项**：模板和 MATLAB 进程数；**选项…**打开上面的设置。
6. 点击**开始空间标准化**。进度条会随图像完成计数。

## 检查结果

<Shot name="spatial-results" alt="配准结果" :marks="[[7, 126], [8, 549], [9, 268, 782], [10, 916, 861]]" />

7. **继续之前，逐一查看每幅配准后的图像。**图片在一幅图像的横断面切片上叠加了模板的脑轮廓：脑应当填满轮廓。仅凭 PET 配准可能失败却不报错，歪斜、缩小或被裁掉的脑会影响之后的每一步。箭头可以切换图像。
8. **表格**列出每幅图像及其输出，点击一行可以显示它。显示**失败**的行没有成功，原因写在表格下方。
9. **在访达中显示**打开项目文件夹。
10. **下一步：强度归一化**继续。之后的页面读取配准后的图像；还没配准的图像不会纳入，第 1 步会说明有几幅。

## 工作原理

软件把每幅图像裁剪到头部周围，把原点移到脑中心，然后在后台由 MATLAB 运行 SPM 的 “Old Normalise”，配准到 PET 模板。患者和对照经过完全相同的配准，这是二者可比的关键。

::: details 对应的命令行
```bash
sugar-pet spatial-norm raw/*_pet.nii.gz -o patients/ --spm-path /path/to/spm12 --jobs 4
```
:::
