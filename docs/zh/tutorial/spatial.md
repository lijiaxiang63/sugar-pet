# 第 1 步：空间标准化

**页面：空间标准化** · 可选 · 需要 MATLAB 和 SPM

这一步的作用是把图像从扫描仪原始空间配准到 MNI 标准空间。**如果你的图像已经在 MNI 空间**（无论之前是用什么工具做的配准），**请直接跳过这一步**，进入[第 2 步](./build-reference)。

## 准备工作

* 本机已安装 **MATLAB**（应用启动后会自动扫描路径）。
* 已下载 **SPM12 或 SPM25**（只需知道 `spm.m` 所在的文件夹路径，不必手动将其添加到 MATLAB Path 中）。
* 待处理的图像为原始空间的 FDG-PET 图像，无需配套的 MRI 结构像。

## 操作步骤

<Shot name="spatial" alt="填好的“空间标准化”页面" :marks="[[1, 120], [2, 412], [3, 458], [4, 573], [5, 634], [6, 'run']]" />

1. **添加原始空间的图像**：将文件拖入列表，或点击**添加文件…** / **添加文件夹…**。Ada 在这里导入了 `study/raw/` 下的六幅图像。如果输入的是 4D 动态图像，程序会自动按时间维取平均。
2. **选择 SPM 文件夹**：指定 `spm.m` 所在的目录。
3. **确认 MATLAB 路径**：如果软件成功找到了 MATLAB，这里会直接显示程序名称；若未自动识别，点击**选择…**手动指定即可。
4. **选择输出文件夹**：Ada 将其设为 `study/patients/`。配准后的图像统一为 2 mm 各向同性体素，命名格式为 `sub-pt01_space-MNI_pet.nii.gz`。
5. **高级选项**（一般保持默认即可）：
   * *PET 模板*：默认使用 SPM 自带的 PET 模板。如果你手头有同批已配准健康对照的均值图，用它作为模板往往能配得更准。
   * *MATLAB 进程数*：设置并行处理的 MATLAB 进程数量。进程越多速度越快，但内存占用也会相应增加。
6. 点击**开始空间标准化**，下方状态栏会实时显示已完成的数量。

## 检查结果

<Shot name="spatial-results" alt="空间标准化的结果" :marks="[[7, 360], [8, 598], [9, 636]]" />

7. **查看结果列表**：表格中会列出每幅输入图像及其对应的输出路径。如果某个文件名标红，说明该图像配准失败，具体报错原因会显示在表格下方。
8. **逐幅目视检查**：在进入下一步前，务必用看图软件把所有配准后的图像检查一遍。纯 PET 配准在个别情况下可能出现大脑歪斜、缩放异常或局部被裁切，且软件不会报错——这类图像一旦混入后续分析，会直接影响结果。
9. 确认无误后，点击**用于强度归一化**，软件会自动跳转到下一个页面并把这些图像填进列表；也可以点击**在访达中显示**直接查看生成的文件。

::: tip 对照组也用同样流程
健康对照组的图像同样需要经过这一步（Ada 将它们输出到了 `study/controls/`）。请确保患者和对照组使用的是完全一致的空间标准化流程。
:::

## 后台原理说明

在后台，软件会先围绕头部区域裁剪图像、将坐标原点移至大脑中心，再调用 MATLAB 运行 SPM 的 “Old Normalise” 模块和 PET 模板进行配准。当然，你也可以用自己习惯的其他工具（如带 MRI 辅助的 SPM 配准或 ANTs）来做空间标准化，只要结果在 MNI 空间，就不会影响后续步骤。

::: details 对应的命令行
```bash
sugar-pet spatial-norm raw/*_pet.nii.gz -o patients/ --spm-path /path/to/spm12 --jobs 4
```
:::
