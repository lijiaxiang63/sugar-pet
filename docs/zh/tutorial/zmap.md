# Z 值图与 W 值图

**页面：Z 值图** · 个案分析第 2 步

Z 值图逐体素显示患者的图像偏离本项目健康对照多远：负值表示摄取较低（低代谢），正值表示较高。

## Z 值还是 W 值？ {#z-scores-or-w-scores}

| | Z 值 | W 值 |
| --- | --- | --- |
| 患者与谁比较 | 全部对照 | 对照对**同龄同性别**者的预测值 |
| 公式 | `(图像 − 对照均值) / 对照标准差` | `(图像 − 预测值) / 对照的残差标准差` |
| 需要 | 无 | [“数据”页面](./project#age-and-sex)上的协变量表 |
| 文件名结尾 | `_zmap.nii.gz` | `_wmap.nii.gz` |

只要患者与对照的年龄有差别，就应使用 W 值：普通 Z 值会把正常老化的影响和疾病的影响混在一起。对照统计对协变量建了模、且表格给出了患者的协变量时，本页会自动生成 W 值图。

## 运行

Z 值图沿用第 1 步的患者和方法，不再询问：它读取第 1 步写出的归一化图像，按对照的方式平滑，再逐体素与对照统计比较。不会为对照生成图，它们是患者比较的对象。第 1 步还没运行，或它运行时所依据的内容此后有变化时，页面会说明，**生成 Z 值图**按钮也不可用。

<Shot name="zmap" alt="“Z 值图”页面" :marks="[[1, 109], [2, 234], [3, 316], [4, 875, 357], [5, 450], [6, 619], [7, 726, 861], [8, 896, 861]]" />

1. **步骤条**：打勾表示该步已完成；点击可以跳过去。
2. **患者**和**方法**：第 1 步归一化的内容。不能生成 Z 值图的方法（自选区域，或对照统计中没有它的方法）会在卡片下方注明并略过。
3. **健康对照**：患者与多少例对照比较，以及它们的平滑。
4. 要修改以上内容，点**返回第 1 步修改**，重新运行后再回来。
5. **协变量表**：决定生成的是不是 W 值图。表格和要校正的列在“数据”页面选择；没有表格时生成普通 Z 值图。
6. **输出位置**：项目的 `zmaps` 文件夹。
7. 点击**生成 Z 值图**。如果第 1 步之后只有协变量表变了，这次运行会先用它重新汇总对照。
8. 完成后，**下一步：帕金森综合征分类**继续。

## 检查结果 {#check-the-results}

<Shot name="zmap-results" alt="一幅 Z 值图和所有图的表格" :marks="[[9, 126], [10, 506], [11, 549]]" />

9. **图片**在患者自己图像的横断面切片上显示一幅图。箭头可以切换，点击表格中的一行也可以。
10. **颜色**：从 −2 到 −5 及以下为蓝色到青色（摄取低于对照），从 +2 到 +5 及以上为红色到黄色。−2 到 +2 之间不着色。W 值图的图例以 *W* 开头，Z 值图以 *z* 开头。
11. **表格**：每幅图像每种方法一行。
    * *最低值*：图中最负的值。
    * *低于 −2*：脑内低于 −2 的体素比例。随机情况下约为 2.3%；广泛低代谢时会多得多。

## 输出文件

`zmaps/` 中每例患者每种方法一幅：`sub-pt01_space-MNI_desc-hn_wmap.nii.gz`，没有协变量时为 `_zmap.nii.gz`。这些图按对照的方式平滑过，所以即使原图没有平滑，它们也是平滑的。

## 阅读 Z 值图

图片只是初步查看。要逐层查看，请在看图软件（MRIcroGL、FSLeyes 或 ITK-SNAP）中把它叠加在 MNI 模板上：

* 用冷色调显示**低于 −2** 的值，查看低代谢区域（−3 更严格）。
* HN 或 PS 之后的正值往往是未受累的区域，而不是真正的高代谢（见[方法怎么选](../reference/methods)）。
* 结果下方提示某例患者的年龄超出对照的年龄范围时，W 值是外推得到的，请谨慎解读。

::: details 对应的命令行
```bash
sugar-pet zmap patients/*.nii.gz -m hn -r hc_reference/ -o zmaps/ --covariates participants.tsv
```
:::
