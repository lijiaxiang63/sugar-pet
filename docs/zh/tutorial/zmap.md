# 第 4 步：Z 值图与 W 值图

**页面：Z 值图** · 个案分析的第 2 步 · 需要参考库

Z 值图用来逐体素衡量一幅图像相对于健康对照的偏离程度，非常适合用来观察单个患者的代谢异常分布：负值代表摄取低于对照（低代谢），正值则代表高于对照。

## Z 值还是 W 值？ {#z-or-w}

| | Z 值 | W 值 |
| --- | --- | --- |
| 比较基准 | 整个健康对照组 | 健康对照中**同年龄、同性别**人群的预期摄取水平 |
| 计算公式 | `(图像 − 对照均值) / 对照标准差` | `(图像 − 模型预测值) / 对照残差标准差` |
| 所需表格 | 无 | 包含患者年龄和性别的协变量表 |
| 对参考库的要求 | 无 | 建库时已勾选并纳入协变量（[第 2 步](./build-reference)第 2 项） |
| 输出文件后缀 | `_zmap.nii.gz` | `_wmap.nii.gz` |

只要患者和对照组的年龄分布不完全一致，就建议优先使用 W 值——普通 Z 值容易把正常的年龄衰老效应和疾病引起的低代谢混在一起。

## 操作步骤

Z 值图是个案分析的第 2 步：它沿用[强度归一化](./normalize)（个案分析的第 1 步）里选定的图像和方法，页面上不再重选。它直接读取第 1 步写出的归一化图像，不再归一化一遍。强度归一化还没有运行，或者运行之后改过图像、方法、参考库或[归一化的设置](./normalize#options)时，本页会提示先回去完成，**生成 Z 值图**按钮暂不可用。

1. **步骤条**：个案分析的三步。打勾表示该步已完成，并且与它前面的步骤一致；点击可以在三步之间切换。
2. **来自第 1 步**：强度归一化所用的图像、方法和参考库，只读。其中某种方法不能制作 Z 值图时（自选区域，或建立参考库时没有勾选它，见第 2 步第 4 项），卡片下方会说明本步略过它。
3. 需要更换图像或方法时，点击**返回第 1 步修改**，改完重新运行强度归一化，再回到本页。
4. **协变量表**（可选）：选中 `participants.tsv` 即可输出 W 值图。注意表格里必须包含这些患者的信息，且列名要与建参考库时勾选的列一致（这里是 `age` 和 `sex`）。留空则输出普通 Z 值图。
5. **输出文件夹**：Ada 选择了 `study/zmaps/`。
6. 点击**生成 Z 值图**。
7. 完成后，旁边出现**下一步：帕金森综合征分类**。

## 检查结果

<Shot name="zmap-results" alt="叠加在脑图像上的 Z 值图，以及结果表格" :marks="[[8, 135], [9, 508], [10, 584]]" />

8. **图片**：把其中一幅图叠加显示在该患者自身图像的横断面切片上。点击图片上方的箭头或表格中的某一行，可以切换到其他图。
9. **颜色**：蓝色到青色表示 −2 到 −5 及以下（摄取低于对照），红色到黄色表示 +2 到 +5 及以上；介于 −2 和 +2 之间的体素不着色。图例开头的 *W* 表示 W 值，*z* 表示 Z 值。
10. **结果表格**：按“图像 × 方法”列出汇总指标：
    * *最低值*：整幅图中最小的负值（反映低代谢最显著的程度）；
    * *低于 −2*：脑内 Z/W 值小于 −2 的体素比例。正常随机分布下这个比例大约是 2.3%，存在大范围低代谢的患者会明显高于这个数。

## 输出文件说明

输出文件夹里会为每幅图像、每种方法生成一幅图：
`sub-pt01_space-MNI_desc-hn_wmap.nii.gz`（未提供协变量表时则为 `_zmap.nii.gz`）。

每幅图都由第 1 步用同一种方法写出的归一化图像得到：软件按参考库的平滑核把它平滑，再逐体素与对照比较。因此即便你输入的是未平滑的图像，最终得到的 Z/W 值图也是平滑后的。

归一化图像必须和对照是同一种归一化方式才能比较。第 1 步设了*目标值*没有关系（软件会先把它除掉）；但*区域统计量*和*估计因子前的平滑*必须与[建立参考库时](./build-reference#options)的一致。不一致时本页会说明两边各用了什么，并给出两条出路：**打开设置…**，把设置改成与参考库一致后重新运行第 1 步；或者**前往参考库**，按现在的设置重新建立参考库。

## 如何查看与解读

页面上的图片只是初步查看。如果要逐层细看，可以用看图软件（如 MRIcroGL、FSLeyes、ITK-SNAP）将结果图叠加在标准 MNI 模板上：

* 可以把**低于 −2** 的体素用冷色调显示出来，这些区域即提示存在低代谢；如果想看更严格的范围，可以把阈值调到 −3。
* 在 HN 或 PS 归一化后出现的正值区域，很多时候只是未被疾病累及的正常脑区，并不一定意味着真正的代谢增高（原因见[方法怎么选](../reference/methods)）。
* 如果结果下方提示某位患者的年龄超出了对照组的年龄范围，说明该患者的 W 值是基于线性模型外推得到的，解读时需多加留意。

::: details 对应的命令行
```bash
sugar-pet zmap patients/*.nii.gz -m hn -r hc_reference/ -o zmaps/ --covariates participants.tsv
```
:::
